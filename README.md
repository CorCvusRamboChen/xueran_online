# 血染钟楼 · Discord 活动（Activity）

在 Discord 里打开的内嵌小程序：机器人发身份、夜里叫人选目标、结算信息、跑提名投票；夜里给所有人「闭眼」（服务器闭麦闭耳）。白天是一张俯视的小镇地图，每个人是一个头顶飘着 Discord 头像的小人，走进小房子就进了那间的私聊语音。

- **剧本**：暗流涌动（Trouble Brewing），5–15 人，22 个角色全部实现
- **说书人**：🤖 机器人全自动，或 🧙 房主当说书人（看魔典、审核/改写每条夜晚信息、杀/救/下毒/改角色/私信）
- **白天自由活动**：小镇地图上有 4–6 间房子（酒馆、教堂、铁匠铺……），点哪儿走到哪儿。走进房子 = 机器人把你拉进那间房子的语音；房子里的人可以锁门，别人只能敲门。所有人都看得到谁在哪间房子（听不到内容）。时间到或主持人喊集合，大家回到座位圈提名投票
- **语音**：入夜所有玩家闭麦闭耳；说书人夜里可以单独把人叫进房间（会先给他解除闭耳）

## 结构

```
src/engine/   规则引擎（纯逻辑，有测试）
src/shared/   小镇地图几何（前后端共用）
src/server/   后端：OAuth 换 token、WebSocket 同步、机器人管语音
client/       前端：Vite + React，打包后由后端托管
test/         node --test
```

## 第一次配置

### 1. 建应用

在 [Discord 开发者后台](https://discord.com/developers/applications) 新建应用：

1. **OAuth2** 页：记下 Client ID、Client Secret；Redirects 里随便加一个 `https://127.0.0.1`（Activity 要求至少有一个）
2. **Bot** 页：Reset Token 记下机器人 token
3. **Activities → Settings**：打开 Enable Activities
4. **Activities → URL Mappings**：

   | PREFIX | TARGET |
   |---|---|
   | `/` | 你的服务器域名（本地开发就填 tunnel 地址，不带 `https://`） |
   | `/cdn` | `cdn.discordapp.com`（头像用） |

### 2. 拉机器人进服务器

把下面链接里的 `CLIENT_ID` 换成你的，打开授权：

```
https://discord.com/oauth2/authorize?client_id=CLIENT_ID&scope=bot%20applications.commands&permissions=298847248
```

这组权限是：查看频道、发消息、连接语音、管理频道、管理身份组（给私聊房间设权限）、移动成员、闭麦、闭耳。

#### 放进别人的服务器时：把机器人关在一个分类里

代码这边已经只动「这一局的人、这一局的频道」（广场、房子、私聊房间）：在别的语音频道聊天的人不会被闭麦、不会被拉走；
机器人自己闭上的麦都记在 `data/voice-held.json`，一定会解开（掉线回来、机器人重启、对局结束或暂停都会解）；管理员事先闭上的人机器人不碰。

再加一道服务器设置上的保险，让机器人在别的频道**根本没有权限**：

1. 授权时把邀请链接里的 `permissions=` 改成只给基本权限（查看频道、发消息、连接语音），不给闭麦、闭耳、移动成员、管理频道。
2. 建一个分类（比如「血染钟楼」），里面放一个语音频道当广场。在这个分类的权限里给机器人的身份组打开：闭麦、闭耳、移动成员、管理频道、管理权限。
3. 从这个分类里的频道启动活动。私聊房间会建在同一个分类下，继承这些权限。

这样就算哪里出了 bug，机器人也碰不到这个分类以外的任何人。

卡住闭麦的人：在小程序里点「语音归位」会把本局不该闭着他的麦解开；机器人每分钟也会把已经结束 / 暂停的局留下的闭麦清掉。

### 3. 填 .env

```bash
cp env.example .env
```

填 `DISCORD_CLIENT_ID`、`DISCORD_CLIENT_SECRET`、`DISCORD_TOKEN`。

### 4. 跑起来

```bash
npm install
```

```bash
npm run build
```

```bash
npm start
```

Discord 只能访问公网 HTTPS，本地开发用 tunnel 暴露 3001 端口，比如：

```bash
cloudflared tunnel --url http://localhost:3001
```

把得到的域名填进 URL Mappings 的 `/`。

## 怎么玩

1. 大家先进同一个语音频道（**房主也要在里面**，机器人把它当城镇广场）
2. 在**文字频道**里点输入框旁的 🚀 应用启动器，选这个活动。
   从语音频道打开的新房间现在进不了大厅，会提示「请从文字频道进入」（进行中的局不拦）。活动是绑定在启动它的频道上的。从文字频道启动，机器人在语音频道之间拉人不会影响活动；从语音频道启动的话，被拉走的人可能会掉出活动（还没在真服务器上验证过）
3. 房主选说书模式 → 大家点「加入游戏」→「开始游戏」
4. 点「我的身份」翻牌看角色；夜里轮到你就点圆圈上的头像选人；信息出现在「收到的信息」
5. 白天先在广场看死讯，然后进入自由活动：点地图走动，走进房子私聊，在房子里可以🔒锁门、回应敲门。电脑上也能用方向键 / WASD
6. 集合后：🗳️ 提名 → 被提名者辩护 → 开始投票（时钟顺时针转，指针经过你时票就锁定）；🏹 开枪（猎手）
7. 房主/说书人用「结束白天」处决台上的人并进入夜晚；⚙️ 菜单里可以拉人、集合、结束本局。自动说书时天亮后会自己开始自由活动，真人说书时由说书人点「自由活动」

## 不连 Discord 测试

`.env` 里设 `DEV_LOGIN=1`，然后浏览器打开（每个标签页是一个玩家）：

```
http://localhost:3001/?name=小明&table=1
```

人不够可以在大厅加机器人玩家。**上线时把 DEV_LOGIN 关掉**，否则任何人都能冒充玩家。

```bash
npm test
```

## 已知限制

- 游戏状态只在内存里，后端重启进行中的局就没了（闭耳状态会记在 `data/asleep.json`，重启后自动解除，不会有人一直被静音）
- 管家的投票限制靠自觉，系统不强制
- 自动说书时，陌客/间谍的「误登记」和镇长替死都是随机决定的
