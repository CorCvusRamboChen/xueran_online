# 血染钟楼 · 地图设计

## 这张地图在游戏里是干什么的

白天的「自由活动」：所有人在小镇里走动，**走进房子就和屋里的人私聊**（Discord 语音自动切过去），可以锁门、敲门、邀请。时间到了集合回广场提名投票。

所以地图不是战斗关卡，它是一台**社交机器**，要服务这几件事：
1. **找人**：想找谁聊，能很快找到他、走过去。
2. **私聊**：有足够多、彼此隔开的房间，人多时也不挤。
3. **被看见**：每个人的位置、和谁一起进了哪间屋子，**全场都看得到**（小地图、左下角存活条、房间条）。去哪、和谁去，本身就是公开的线索——"你们俩为什么一起去了墓园？"
4. **偶遇**：路上会碰到人，临时拉进屋聊几句。
5. **集合**：时间到了，从任何地方都能很快回到集合点。

## 一张地图的"身份证"（每张图先填这张表）

| 项 | 要回答的问题 |
|---|---|
| **主体** | 这座镇子的核心是什么建筑/地方？（暗流涌动：钟楼广场；不能两张图是同一种） |
| **地标（weenie）** | 从地图任何地方都看得见、能用来认路的一个大剪影（暗流涌动：广场中央的钟楼）。最多两个：一个主、一个辅 |
| **路网结构** | 网格 / 放射 / 一条主街 / 环形 / 被河或悬崖切开的两岸 / 台地……每张图选一种**不同的**拓扑 |
| **相遇引擎** | 大家必经、容易碰面的窄口：桥、巷子、台阶、城门（Among Us 的 Skeld 靠窄走廊制造碰面） |
| **远处的房间** | 至少一间偏远的私聊点：去那里更隐秘，但一路都被人看见，而且回来晚。它是"冒险换隐私"的选择 |
| **分区** | 3–4 个气质不同的片区，各有自己的材质、光线、声音，看一眼就知道在哪一区 |
| **季节、时刻、天气** | 每张图不同（暗流涌动：雪夜；不要两张图都是雪夜） |
| **环境叙事** | 不用文字、只靠摆设讲出来的事：被翻开的新坟、门上的抓痕、没喝完的茶 |
| **剧本的呼应** | 地图和这个剧本的角色有关：房子、摆设对应剧本里的角色和背景故事 |

## 设计原则（研究结论，按我们的游戏改写）

### 布局
- **先灰盒，再美术**（所有关卡设计 skill 的第一条）。先用方块和线条定下房子、路、桥、地标的位置，在游戏里实际走一遍、用机器人跑几局，确认好找、好走、不挤，再让 Codex 画。改方块几分钟，改画好的图要几天。
- **集合点要居中**：从最远的房子走回集合点不超过约 8 秒（走路速度 240 单位/秒 → 距离不超过约 1900 单位的路程）。
- **房间之间要隔开**：两间私聊房的门相距至少 250 单位，免得门口互相偷听、互相挡路。
- **房间数量随人数**：人少开 4–5 间，人多开 6–7 间。少于一半人数的房间时，大家要排队等，容易无聊。
- **至少一个闭环**，不要只有死胡同：从一片区可以绕另一条路回来，避免"去了只能原路返回"。
- **窄口要有替代路**（相遇引擎旁边留一条更远、更安静的路），不然大家只会在一个点挤成一团。
- **偏远房间要有回报**：更隐秘、风景好、有独特的摆设，否则没人去，成了死角（Among Us 的 Polus 就有这个问题）。

### 引导和可读性
- **光引路**：窗光、灯笼、篝火亮的地方人会过去。能进的房子窗户亮着；不能进的建筑窗户暗。
- **能进 = 亮灯**，这条约定只给能进的房子用，**不要**拿来装饰（一旦装饰也亮，玩家就分不清了）。
- **地标在每个路口都看得见**，不要被前景建筑挡住（暗流涌动里前景房子挡钟楼的问题我们已经用半透明处理过）。
- **门开在看得见的一面**：等距视角下只有南面和东面朝向镜头，门只能开在这两面（墓园这种露天的例外）。
- **不能走的地方要看起来就不能走**（水、悬崖、密林、栅栏），不要靠看不见的墙。

### 节奏
- 地图本身就是一天的节奏：**集合点 = 喘口气、公开的地方；房间 = 紧张、私密的地方**。路上的相遇引擎是两者之间的过渡。
- 片区要有对比：开阔 ↔ 狭窄、明亮 ↔ 昏暗、热闹 ↔ 安静。

### 美术（交给 Codex 时）
- 等距视角（投影 `[x−y, (x+y)/2−z]`），极乐迪斯科式油画；底图 + 每栋能进的房子分开画（外观 / 亮灯外观 / 剖开的室内）。
- 底图边缘做"颜色往外扩散渐隐成黑"。
- 房子的占地框必须是正南北走向的矩形（门、遮挡排序、进出判定都靠它）；河、悬崖、树林可以是任意形状。
- 先出灰盒参考图（`town-guide` 那样的方块图），Codex 照着它的透视和布局画，房子的空地留空。

## 地图数据要有的东西（给程序）

每张地图一份数据：尺寸、集合点（圆心 + 半径，开局大家站一圈）、地标（不能走的圆）、水域/悬崖（不能走的多边形或折线带）、桥（水上能走的矩形）、道路（折线 + 半宽，只影响画法）、能进的房子（矩形 + 门朝向 + 开放顺序）、不能进的建筑（矩形）、树林等装饰障碍（圆）。寻路、进屋判定、机器人溜达、座位站位都只读这份数据。

## 评审清单

- [ ] 身份证九项都填了，主体、地标、路网结构、季节和已有地图都不一样
- [ ] 灰盒在游戏里跑过：机器人和真人都能找到每间房，没有走不到的地方
- [ ] 最远房间到集合点 ≤ 约 8 秒；房门两两相距 ≥ 250
- [ ] 有至少一个相遇引擎、一条替代路、一个闭环、一个偏远房间
- [ ] 每个路口能看见地标；能进的房子都亮灯，不能进的不亮
- [ ] 不能走的地方看起来就不能走
- [ ] 房子、摆设和剧本角色有呼应
