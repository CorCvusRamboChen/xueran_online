# 血染钟楼 · 3D 人物设计

## 这些小人在游戏里是什么样

- 地图是 2:1 斜视角（相机仰角 30°、从东南往西北看），人物在地图上**只有五六十像素高**，脸基本看不清。
- 一局最多 15 人同时在场，大家要能**隔着半张地图认出「那是铁匠」「那是修女」**。
- 画风是极乐迪斯科：油画笔触、偏旧的颜色——但**旧不等于灰**，人要有血色。

所以这里的人物设计，**剪影和色块比脸重要得多**。

## 三层读法（按顺序做，前一层不过关别往后做）

1. **剪影**（涂成纯黑也认得出）：头顶的形状（帽子、发型、头巾）、身体的块（胖 / 瘦 / 高 / 矮 / 驼背）、下摆的长度和形状（短外套 / 长风衣 / 拖地的裙或袍子）、背上 / 腰上的一件标志物。
2. **色块**（眯着眼看）：每个人有**一块主色**（一件大衣服），和别人的主色在色相上拉开（但仍是旧旧的颜色，不要鲜艳）；上下身明暗要有对比（浅上衣深裤子，或反过来）。
3. **细节**（只在前两层成立后加）：脸、徽章、纽扣、补丁——地图上看不到，只给预览和大图用。

## 剪影：每个人至少占两个「独有」的格子

| 维度 | 可选 |
|---|---|
| 头顶 | 光头 / 乱发 / 发髻 / 辫子 / 鸭舌帽 / 软呢帽 / 高礼帽 / 宽檐帽 / 圆盘帽 / 厨师帽 / 毛线帽 / 头巾 / 修女头巾 / 军帽 |
| 身形 | 壮宽 / 胖圆 / 高瘦 / 矮小 / 驼背 / 挺直 |
| 下摆 | 齐腰短外套 / 及膝 / 及踝长袍 / 宽大的裙子 |
| 标志物（贴身、不拿在手里） | 背上的铲子 / 腰上的大钥匙 / 胸前的勋章 / 围裙 / 长围巾 / 斜挎包 |

同一批人物里，**两个人在「头顶 + 身形」上不能完全一样**。像的就换一个（比如警探和镇民都是风衣 + 软呢帽，只留一个）。

## 鲜活，不要僵尸

僵尸感来自：灰绿的脸、发青的暗部、全身一个灰调、空洞的眼神、垂着的姿势。概念图里要写明：
- 皮肤**暖色、有血色**（脸颊、鼻尖、手微红），不要灰绿、不要惨白；
- 每个人有一种和别人不同的主色（芥末黄、铁锈红、橄榄绿、深紫……），但提示词里只用平常话写「X 是他身上最显眼的颜色」，整体仍偏灰偏旧；
- 表情有性格（疲惫可以，但要「活着的疲惫」），眼睛有神；
- 站姿：A 字站姿是给绑骨用的，但肩背要有人物气质（驼背的老人可以驼，修女端正）。

游戏里的着色器也会帮忙：暖色（皮肤、皮革、红色）保留并提一点血色，暗部不压蓝（见 `client/src/world/avatar3d.js` 的 SKIN_FRAG）。

## 给 Codex 的概念图要求（这个管线的硬限制）

每个人正面、背面各一张，1024×1536：
1. 全身、居中，帽子到鞋底都在画里；**正交平视**、平光、无投影，纯浅灰背景 `#d9d9d9`。
2. **A 字站姿：双臂向两侧张开约 45°，上臂和身体之间、两腿之间都要看得到背景**（胳膊贴身 Mixamo 会把袖子绑到躯干上，走路时手缩到肚子前）。
3. **手里不拿东西**；标志物都贴身挂着（背、腰、胸）。
4. 宽裙子、长袍可以，但下摆不要拖地、两脚要露出来。
5. 正面、背面是同一个人：同样的衣服、体型、站姿。
6. 照着大厅里这个人物的画像（`client/src/assets/art/people/<id>.webp`）画脸和气质。
7. 油画笔触、颜色块分明，但轮廓清楚。

## 给 Codex 的提示词模板（一次一个人，前一个过关再做下一个）

**用第一版（镇民、铁匠、学生）的写法：平实地描述一个真实的人，不要写游戏设计术语。**

试过的教训（11-11）：
- 第一版只写「什么人、多大、什么身材、穿什么（每件衣服一个颜色）、什么表情」+「像极乐迪斯科那种油画人物立绘，整体偏灰偏旧」+ 七条画法要求 → 自然，用户满意。
- 后来加上「剪影要夸张」「主色占 40% 要饱和」「64 像素也要看得到」「不要照抄参考图配色」→ 模型把人画成游戏道具：大头、颜色艳、钥匙巨大，越改越怪。**不要再写这类话。**
- 人和人分不分得开，靠我们在设计卡里给每个人**不同的帽子 / 体型 / 外套长度 / 一种不同的主色**，再用平常话写进描述；不是靠叫模型「画夸张」。
- 只多加两条验证过的：胳膊张开约 45°、能看到腋下空隙（铁匠那次）；脸颊 / 鼻尖有点血色（防僵尸）。

模板（把【】换掉；描述用一段自然的话，像在给画师讲这个人）：

```

画法要求（这几条对 3D 生成很重要，必须做到）：
```

## 评审：做出来以后怎么检查

- **剪影测试**：在预览页（`?preview=avatar&avatar3d=glb&char=<id>`）把所有人的待机帧排一排，眯眼看 / 缩到 60 像素高看，能不能一个个叫出名字。
- **斜视角**：从地图的 45° 看，头顶和肩膀占了大部分画面——帽子、发型最能认人。
- **不像僵尸**：放大看脸和手是暖的；整个人不是一团灰。
- **动作**：走、跑时胳膊不穿进身体、裙摆不劈成裤子太多（Mixamo 对长袍会这样，能接受轻微）。

| 项 | 内容 |
|---|---|
| 一句话 | 这个人是谁、给人什么感觉 |
| 剪影 | 头顶 / 身形 / 下摆 / 标志物 |
| 主色、辅色 | 主色占大块；和其他人拉开色相 |
| 身高 | rig.py 第 7 个参数（米，连帽子） |
