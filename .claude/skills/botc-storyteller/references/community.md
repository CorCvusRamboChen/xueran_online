# 社区剧本（第二批，2026-11-14）

用户要「经过多人验证好玩的热门剧本」，挑了这四个。角色表对过多份公开的剧本 JSON（solobotc、s-thom、clockipedia 等），官方能力、相克、夜晚顺序取自 TPI 官方仓库 botc-release 的 roles.json / jinxes.json / nightsheet.json。botcscripts.com 有人机验证，不绕。

中文名除「大诚小镇」外都是本项目起的。

## 新角色的口径

- **小精灵**：首夜得知一个在场的镇民角色（不告诉是谁）。失效时可能给不在场的镇民。白天「疯狂」地证明自己是那个角色（收音页转写交给大模型，黄昏判）；判定过一次就算疯狂过。那个镇民死时，小精灵活着、疯狂过、没失效，就获得他的能力（不通知，下次被叫醒才知道）。没疯狂过不罚，只是拿不到。
- **将军**：每晚得知说书人认为哪边在赢：局势分 > 0.25 善良、< −0.25 邪恶，其余「都不是」。失效时给另外两种之一。
- **政客**：终局判。输掉的一方里，按处决记账：处决了自己人，提名的人 2 分、举手的人 1 分；政客分数本方最高且至少 3 分，就转阵营和赢的一方一起赢。醉酒中毒、被麻脸巫婆从邪恶变成政客的不转。不管怎么分出胜负（圣徒、哥布林、利维坦……）都判（`Game.setWinner` 里调）。官方没有公式，这是近似。
- **食人魔**：首夜选一名其他玩家，变成他的阵营（醉酒中毒也生效），自己不知道是哪边（身份牌按他以为的显示）。相克：间谍一定算邪恶；陌客被当作邪恶时食人魔得知自己是邪恶。他选的人以后转阵营，他不跟着转。
- **灵言师**：首夜得知一个关键词（`MEZ_WORDS` 里挑，生僻词）。第一个说出它的善良玩家当晚变成邪恶（被告知）。说出口时灵言师醉不醉不管，看夜里：当晚灵言师失效，那人不变、能力也用掉。
  - 听法（用户 11-14 定的）：剧本里有灵言师时，每天给所有活着的真人发收音页（不看灵言师在不在场，免得暴露），本机转写的文字里找关键词（去掉空格标点，子串匹配），不交给大模型。没开收音的人说了听不到。

## 相克（实现了的）

- 魔术师 / 提线木偶：魔术师活着时，恶魔只知道提线木偶坐在旁边，不知道是哪边。
- 洗脑师 / 哥布林：洗脑师可以让人对「自己是哥布林」疯狂。
- 利维坦 / 麻脸巫婆：第 5 天以后麻脸巫婆造不出利维坦。
- 麻脸巫婆 / 落难少女：麻脸巫婆造落难少女时，由说书人挑哪名玩家变。
- 麻脸巫婆 / 政客、食人魔：被变成政客 / 食人魔的邪恶玩家不能靠自身能力转为善良。
- 陌客 / 食人魔、间谍 / 食人魔：见上。

没做：提线木偶 / 气球驾驶员（提线木偶以为自己是气球驾驶员时开局可能多一个外来者）；食人魔的可选规则「挚友」（只建议 15 人以上）。

## 瞒天过海（Boozling v9，`booz`，2026-11-14 加）

用户要「中国社区比较热门的剧本」。中文圈找不到热度排行；瞒天过海是 2022 剧本世界杯冠军（作者 Lau），集石有官方中文名，B 站「染钟楼」中文社区的剧本博物馆专栏写过：v8 争议大，v9 改顺了、适合新手进阶。华灯初上那批国风原创剧本更「中国社区」，但新角色太多，没选。

角色：贵族、小精灵、女祭司、气球驾驶员、占卜师、神谕者、博学者、哲学家、巡山人、渔夫、猎手、贤者、食人族；酒鬼、畸形秀演员、落难少女、呆瓜、魔像；男爵、洗脑师、红唇女郎、提线木偶；诺-达鲺、方古、小恶魔。

- **女祭司**：每晚得知说书人认为她最该和谁聊。善良落后时多指拿着真信息的善良玩家，善良领先时常指一个邪恶玩家（骰子 priestessGood / priestessEvil）；失效时随便指。
- **巡山人**：[+落难少女]（`rollMixed` 保证落难少女在场）。每局一次，夜里选一名存活的玩家：是落难少女就变成一个不在场的镇民（被告知）。失效时这一次也用掉。
- **魔像**：整局只能提名一次（第二次直接不让提）；提名的人不是恶魔（陌客可能被当作恶魔）就当场死，提名照常进行。失效时不死，这一次也用掉。
- 相克：红唇女郎 / 方古（方古跳人时红唇女郎不变恶魔，原来就是这样）；提线木偶 / 巡山人、提线木偶 / 气球驾驶员：说书人不让提线木偶以为自己是这两个（不然开局要多放外来者）。
- 地图：黯月驿站的变体「醉醺醺的旅店」（琥珀暖光）。

## 裁缝与暴乱（`sar`，2026-11-15 加）

用户发来一张小红书帖子的截图：杭州说书人「牧师」推荐的极速板子，作者 Sui、美术 Lei，剧本卡上只有三个角色。帖子说它「至今没见过比这个板子更快结束的局」，第一天就会吵起来。

- **所有善良都是女裁缝**：每局一次，夜里选两名其他玩家，得知他们是不是同一阵营。可以有很多个女裁缝，各用各的一次。
- **所有邪恶都是暴乱**：人数照标准表，爪牙加恶魔的位置全换成暴乱（`rollRiot`）。7 人及以上时，所有暴乱在恶魔信息这一步一起醒来互认；没有伪装可拿。暴乱夜里不醒、不杀人。
- **暴乱用的是剧本卡上的旧版（v1）文字**：「被提名的玩家死亡，但他可以立刻再次发起提名（第三天白天他必须这么做）。在第三个白天结束时，邪恶阵营获胜。」2024-12 官方已经改成新版（只在第三天暴乱、爪牙变暴乱），这里照卡上的旧版。运作方式照官方实验角色运作文档（BotC Experimental Characters Comprehensive How to Run）里的「How to Run Riot v1」：
  - 任何人被提名都当场死亡，不投票，不算处决。
  - 他可以立刻接着提名（死了也能、今天提名过也能）。线上给 20 秒点人（`riotSeconds`；现场是数 3、2、1）。
  - 第一、二天：他不提名、或时间到了，今天的提名就结束，入夜。
  - 第三天：必须提名。时间到了说书人替他挑一名存活玩家（`riotPick`，记进决策日志）；没有人开头，说书人提名第一个人（`riotStoryteller`）。
  - 死人不能被提名；每人每天还是只能被提名一次。
  - 所有活着的暴乱都失效时能力不在，提名投票照常（这个剧本没有醉酒中毒，只是留了口子）。
- **胜负**：所有暴乱死了，善良当场获胜。只剩两人邪恶获胜。第三个白天结束时暴乱还活着，邪恶获胜。
- **传奇角色骗人精**：每局一次，一名善良玩家可能得到错误信息。这里就是女裁缝的某一次结果被说书人反过来，用骰子 `fibbin`（base 0.2，善良领先时更容易）决定；用掉了就再也不会。
- **没有照做的地方**：v1 文档写「第三天开始时只剩三人，大家一起指定谁先提名」。这里没做，按新版的做法，由说书人提名第一个人。
- **地图**：钟楼广场的变体「暴乱的三天」，橘红烟雾，飘火星和灰（weather `embers`）。
- **测试**：`test/riot.test.js`。

## 夜半狂欢（The Midnight Oasis，`mo`，2026-11-16 加）

用户发来剧本卡：作者 Zets，钟楼剧本博物馆美术，「旋转木马」快速上手剧本，支持 7–15 人。

- **角色（23 个）**：
  - 镇民：贵族、舞蛇人、气球驾驶员、巡山人、工程师、渔夫、教授、博学者、失忆者、农夫、食人族、罂粟种植者、无神论者。
  - 外来者：酒鬼、理发师、魔像、落难少女。
  - 爪牙：投毒者、精神病患者、灵言师、麻脸巫婆。
  - 恶魔：哈迪寂亚、亡骨魔。
- **传奇角色**：
  - 哨兵：外来者三分之一多一个、三分之一少一个、三分之一照常（`sentinelShift`）。
  - 圣洁之魂：邪恶玩家最多比开局多一名（`ivoryFull`）。这个剧本里只有灵言师会多出邪恶，所以它挡的是灵言师的第二次转人。

新角色的口径照英文官方百科：

- **工程师**：每局一次，夜里选一个恶魔角色或爪牙角色（只能选剧本里的）。
  - 选恶魔：整个恶魔换掉。
  - 选爪牙：官方是「选哪些爪牙在场」，可以一次选好几个。这里一次只选一个角色，由说书人挑一名爪牙换成它。
  - 选的角色本来就在场：不变，能力照样用掉。
  - 被换的人当晚被叫醒告知新角色；换成灵言师时补发关键词。
  - 失效时不变，能力也用掉。
- **罂粟种植者**：他活着、没失效时，首夜跳过爪牙和恶魔信息，只给恶魔 3 个伪装。
  - 他死了（没失效），当晚（夜里死的就在当晚结束时）爪牙得知恶魔、恶魔得知爪牙，不再给伪装。
  - 失效时死了，邪恶不会互认（官方）。
  - 卡上的相克「食人族获得罂粟种植者能力」没做：食人族只在罂粟种植者被处决后才能拿到这个能力，而那时邪恶已经互认了。
- **精神病患者**：每天一次，提名开始前（天亮到集合开放提名之前）可以公开选一名玩家，他死亡。只有真精神病患者看得到按钮。
  - 失效时没人死，当天这次也用掉。
  - 被处决时要猜拳：对手是提名他的人，自己提名自己就和说书人猜。时间 `rpsSeconds` 20 秒，没出的随机出。他输了才死；平局或赢了就活下来，这次仍算今天的处决。
- **哈迪寂亚**：除首夜外每晚可以选三个人（可以选死人、选自己）。
  - 结算停下来按顺序一个个问（`ahStep`）：选死就死，死人选活就复活。三个人最后都活着就一起死。
  - 被选中的人自己当晚的选择先存起来，问完再放回，所以教授、巡山人这些在它之后行动的人不受影响。
  - 天亮公布选了谁、现在谁活着，各自怎么选的不公开。
  - 失效时什么都不发生。
- **无神论者**：官方是说书人决定放不放。这里有 15% 的局（`ATHEIST_SHARE`）是无神论者局，不是这种局就不发无神论者，但酒鬼可能以为自己是他，邪恶也能拿他伪装。
  - 无神论者局没有爪牙和恶魔，空出来的位置补镇民。
  - 说书人整局用一个假世界：从无神论者以外的人里挑出「爪牙」加「恶魔」，人数照标准表。所有信息都按假世界给，每晚杀一个假世界里的「好人」。假恶魔死了，就改让另一个「邪恶」当恶魔。
  - 有无神论者的剧本里，活人随时可以提名说书人：不辩护，投票从提名者的下一位转起。说书人被处决时，无神论者局善良获胜，否则邪恶获胜。
  - 无神论者局只剩两人：善良落败。
- **夜晚顺序**：照官方英文总表。`MIX_STEPS` 加了 poppygrower、engineer、alhadikhia。
- **地图**：黯月驿站的变体「午夜的旋转木马」，冷紫色灯雾，放烟花（weather `festival`）。
- **测试**：`test/midnight-oasis.test.js`。
