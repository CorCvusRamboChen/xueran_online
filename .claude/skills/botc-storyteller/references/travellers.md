# 旅行者（botc-bot 里的做法，2026-11-16，全部照集石官方百科）

官方：旅行者是给开局后才来、或者要提前走的人用的。角色公开，阵营由说书人决定（不公开，大多数情况让旅行者善良）；邪恶旅行者得知恶魔、不知道爪牙；善良旅行者什么都不知道。

## 加入、离开、流放

- **加入**：观战的人，任何时刻（官方）；夜里加入的当晚不醒，下一晚才是他的「首个夜晚」。官方建议还有 7 名或更多玩家（不算旅行者）存活时才加入旅行者，AI 说书人照这个开放。最多 20 人。每个旅行者一局一个。座位接在圈的最后；「N 人局」和角色配置不算旅行者。
- **阵营**：AI 说书人掷 `dice.travellerEvil`（基础 20% 邪恶；善良领先时多给邪恶；已有邪恶旅行者就少给）。
- **流放**（官方「术语汇总」「旅行者」页）：任何玩家（含死人）都能提议，不能提议流放自己；每名旅行者每天只能被提议一次，一天能流放任意多个；支持数 ≥ 所有玩家（没离开的）的一半；死人支持不消耗投票标记；**角色能力不能以任何形式影响流放**（窃贼、官员、巫毒师、僧侣都不管用，唯一的例外是怪咖自己的能力）；流放不是投票也不是处决，今天照样可以处决别人。
- **不能被提名处决**；可以随时离开（算出局，不能投票、不能提名）。
- **胜负**：「只剩两名存活玩家」和「全是邪恶」不算旅行者。

## 16 个旅行者怎么结算

夜晚顺序照官方英文总表：学徒、咖啡师、官员、窃贼（首夜），咖啡师、官员、窃贼、流莺、集骨者（其他夜）都在夜晚最前面。

| 角色 | 剧本 | 做法 |
|---|---|---|
| 窃贼 | 暗流 | 每晚选一名别的玩家：他明天的票算负数 |
| 官员 | 暗流 | 每晚选一名别的玩家：他明天的票算三票 |
| 枪手 | 暗流 | 每天一次，当天第一次处决投票统计后：打死一名**在这第一次投票里**投过票的人（流放举手不算） |
| 替罪羊 | 暗流 | 同阵营的人被处决时说书人可能让他替死，算当天的处决（`dice.scapegoat` 40%；邪恶替罪羊遇到恶魔被处决时约九成替死） |
| 乞丐 | 暗流 | 只能用投票标记投票（开始没有）；死人白天可以把自己的投票标记交给他（公开），乞丐私下得知那人的阵营，给了的人不能再投；投一次用一个；不会中毒醉酒；乞丐死后照常有一张幽灵票 |
| 法官 | 黯月 | 每局一次，别人发起的提名，从被提名到下一次提名之前（统计完也行）：强制成功 = 这个人直接被处决、当天提名结束；强制失败 = 这次算 0 票、提名继续。中毒醉酒也算用掉 |
| 巫毒师 | 黯月 | 只有他和死人能投票，死人投票不消耗标记，处决不需要过半数（1 票就够） |
| 女舍监 | 黯月 | 每天一次宣布至多三对玩家交换座位（按顺序执行，新座位一直有效，相邻类能力跟着变）。官方「只能在座位上和相邻的玩家耳语」：线上私聊就是进房子，女舍监在场时屋里只要有一个人不是你的左右邻座，就进不去、也邀请不进来 |
| 主教 | 黯月 | 只有说书人提名。AI 说书人每天提名 3–5 人，至少一名和主教阵营相反的；主教善良时多提名邪恶、邪恶时少提名邪恶；只剩 4 人以下时全部提名。真人说书人在玩家菜单里点「提名他（主教）」。被提名的人辩护、大家照常投票 |
| 学徒 | 黯月 | 首个夜晚：善良拿一个镇民能力、邪恶拿一个爪牙能力（剧本里的任何一个，优先不在场的），保留到死；只在首夜生效的能力（祖母、教父的外来者信息）当晚就给。他还是学徒：探查类能力（赌徒、侍臣）看的是学徒，能力判定用 `abHolder` / `gained` 认他 |
| 怪咖 | 梦殒 | 今天表现得很有趣就不能被流放。由说书人判断：线上在流放举手时大家点「😂 他今天很有趣」，一半的人点了就算有趣 |
| 集骨者 | 梦殒 | 每局一次，夜晚*：选一名死亡玩家，他重新获得能力到下个黄昏（`regained`）；他的能力今晚还没轮到就叫醒他行动。亡骨魔留着能力的爪牙不能「重新获得」 |
| 咖啡师 | 梦殒 | 被动，说书人每晚选一名玩家和一种效果，叫醒他告诉他：① 直到黄昏清醒且健康并获得正确信息（涡流、醉酒中毒都不影响）；② 能力生效两次：每晚选人的能力，这一步结算完再叫醒他选一次（官方建议优先把 ① 给不能从行动两次里受益的角色） |
| 流莺 | 梦殒 | 夜晚*：选一名存活玩家，叫醒他问同不同意（机器人善良的多半同意）；同意就得知他的角色（不是阵营），说书人可能让两人一起死（`dice.harlotDeath` 30%，不会因此杀死恶魔结束游戏） |
| 屠夫 | 梦殒 | 首次处决后（线上是黄昏处决之后）可以再提名一个人（今天被提名过的也行），大家举手，过存活玩家的一半就处决，不用超过之前的票数；没有处决就不能用，流放不算处决 |
| 侏儒 | 七步成诗（实验性） | 加入时说书人公开宣布一名与他同阵营的玩家（同伴）；每当同伴被提名（陈述、辩护时），侏儒可以公开杀死提名者，辩护和投票照常 |

失效（中毒 / 醉酒）的旅行者能力不生效，按各引擎自己的判断（乞丐除外）。

## 和官方不一样的地方

没有了（2026-11-16 用户：全按官方百科，消除差异）。说书人有选择权的地方（阵营、学徒拿哪个能力、咖啡师选谁和哪种效果、流莺是否同死、替罪羊是否替死、主教提名谁）由 AI 说书人按官方建议掷骰决定。
