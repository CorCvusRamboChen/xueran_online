# 旅行者（botc-bot 里的做法，2026-11-16）

官方：旅行者是给开局后才来、或者要提前走的人用的。角色公开，阵营由说书人决定（不公开）；邪恶旅行者知道恶魔是谁。

## 这里怎么做

- **谁能加入**：观战的人，白天（官方是任何时刻都能加入，线上夜里不好插进夜晚顺序，所以只在白天；官方建议存活 7 人以上再加），暗流涌动 / 黯月初升 / 梦殒春宵三套引擎的剧本（含社区剧本），不含裁缝与暴乱、新手教程、狼人杀、阿瓦隆、暗印。最多 20 人。每个旅行者角色一局只能有一个。
- **座位**：接在圈的最后。顶上「N 人局」和角色配置不算旅行者。
- **阵营**：AI 说书人掷 `dice.travellerEvil`（基础 20% 邪恶；善良领先时多给邪恶；已经有邪恶旅行者就少给）。邪恶的私下得知恶魔是谁。
- **流放**（不是处决）：任何玩家（死人也行）白天可以提议流放一名活着的旅行者，每名旅行者每天只能被提一次，不能提议流放自己。所有人举手（死人不消耗投票标记），支持数 ≥ 所有未离开玩家的一半（向上取整）就流放 → 死亡，记入时间线「被流放」。流放期间提名暂停，结束后照常；今天照样可以处决别人。
- **不能被提名**：要让旅行者出局只能流放。
- **离开**：旅行者随时可以离开，算出局，不能投票、不能提名。
- **胜负**：「只剩两名存活玩家」和「全都是邪恶」只数非旅行者。旅行者跟着自己的阵营输赢。

## 流放（官方百科「术语汇总」「旅行者」页）

任何玩家（含死人）都能提议；每名旅行者每天只能被提议一次，一天能流放任意多个；支持数 ≥ 所有玩家的一半（不是存活玩家）；死人支持不消耗投票标记；**角色能力不能以任何形式影响流放**（窃贼、官员的票数，巫毒师，僧侣保护都不管用）；流放不是投票、也不是处决。邪恶旅行者得知恶魔、不知道爪牙；善良旅行者什么都不知道。

## 做了的 6 个

| 角色 | 版本 | 做法 |
|---|---|---|
| 窃贼 | 暗流 | 每晚选一名非自己的玩家：他明天的投票算负票 |
| 官员 | 暗流 | 每晚选一名非自己的玩家：他明天的投票算三票 |
| 枪手 | 暗流 | 每天一次，当天第一次处决投票统计之后：打死一名**在这第一次投票里**投过票的人（流放举手不算投票） |
| 替罪羊 | 暗流 | 同阵营的玩家被处决时，说书人可能让替罪羊替他死，算当天的处决（`dice.scapegoat` 40%；邪恶替罪羊遇到恶魔被处决时约九成替死，官方说大多数情况要阻止邪恶输掉） |
| 法官 | 黯月 | 每局一次，别人发起的提名，从被提名到下一次提名之前（统计完也行）：强制成功 = 这个人直接被处决、当天的提名结束；强制失败 = 这次算 0 票、提名继续。中毒醉酒也算用掉 |
| 巫毒师 | 黯月 | 只有他和死人能投票；死人投票不消耗标记；处决不需要过半数（门槛 1） |

失效（中毒 / 醉酒）的旅行者能力不生效，按各引擎自己的判断。

## 没做的 9 个（原因）

乞丐（要做「谁给了死人票」的交接）、学徒（要临时获得一个镇民/爪牙能力，三套引擎各不一样）、女舍监（要在白天换座位）、主教（只有说书人提名，和 AI 说书人流程冲突）、异类（靠真人说书人判断「最好笑」）、集骨者、咖啡师、交际花、屠夫（都要跨引擎改夜晚或提名规则）。后面有需要再逐个加。
