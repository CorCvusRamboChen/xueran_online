# 通用规则与说书人理念

蒸馏自《染·钟楼谜团》官方中文百科的规则页：规则概要、规则解释、重要细节、术语汇总、钟楼谜团隐性规则汇总、相克规则、给说书人的建议、设计师的平衡天书、哪些是“可以但不建议”、“规则”与“理念”、疯狂规则如何运作、设计师总结的国内玩家对染的错误理解、成为一个好说书人的经历、夜晚行动顺序一览。

适用范围：只有《暗流涌动》和《黯月初升》，**不用旅行者，不用传奇角色**。原文里只跟旅行者、传奇角色、其他剧本有关的内容已删掉。单个角色怎么结算，看各剧本自己的参考文件；本文件管通用流程、术语和说书人怎么做判断。

## 1. 游戏流程规则

### 1.1 设置

1. 玩家围坐成一圈（圆形、方形都行），座次要能分清顺时针和逆时针。魔典里各角色的排列顺序必须和现实座次一致。
2. 选剧本。《暗流涌动》要 5 名或更多玩家；《黯月初升》建议 7 名或更多（沙巴洛斯、莽夫等角色在 5～6 人局里对某一方很不公平）。新说书人建议先开《暗流涌动》，先带一两局 5～10 人的游戏。
3. 按人数从剧本里秘密选出对应数量的镇民、外来者、爪牙、恶魔（人数配置表见官方旅行者列表或各剧本参考文件）。不用旅行者，所以一局最多 15 人。
4. 处理方括号能力（角色标记上的 `[...]`，比如男爵的 `[+2 外来者]`，就是加两个外来者、去掉两个镇民；酒鬼也有类似的设置调整）。方括号能力**只在设置阶段生效**，游戏中途变成这个角色也不会触发。调整完以后，角色数必须等于玩家数。
5. 角色标记洗混后由玩家盲抽，各自秘密查看，再交回说书人放进魔典。
6. 选角色要谨慎：选你觉得有趣、互动好、自己处理得来的组合。第一局可以用剧本页的推荐配置。

### 1.2 首个夜晚

1. 让所有人闭眼，进入黄昏，然后按“首个夜晚”顺序表从上往下结算。
2. **7 人及以上**才有这两步，排在所有角色行动之前：
   - **爪牙信息**：同时唤醒所有爪牙，让他们互相看到，展示“他是恶魔”并指向恶魔。
   - **恶魔信息**：唤醒恶魔，展示“他们是你的爪牙”并逐个指向爪牙，再展示“这些角色不在场”和三个**不在场的善良角色**，供他伪装。最好给两个镇民加一个外来者，让他既能伪装镇民也能伪装外来者。恶魔也可以不用这三个角色。
3. 不到 7 人：没有爪牙信息和恶魔信息，邪恶玩家互相不认识，恶魔也拿不到伪装。
4. 首个夜晚之前，尽量不让玩家讨论自己的角色（可以直接禁止）。游戏从第一个夜晚以后才算真正开始。
5. 夜里玩家可以说话，但说书人要禁止聊当晚发生的事，也不允许玩家边用能力边报出自己在做什么。

### 1.3 夜晚（通用）

1. 只唤醒今晚**确实需要行动**的玩家。顺序表上有某个角色，不代表一定要叫醒他（比如守鸦人只有在夜里死了才醒）。
2. 一次唤醒一个人，结算完再让他入睡。放好相应的提示标记（比如投毒者选完人后，在目标旁放“中毒”）。
3. 在被唤醒之前已经死亡的玩家，当晚不会醒来（能力写明“即使你已死亡”或“当你死亡时”的除外）。
4. 能力用出来就**立即生效**：恶魔先杀了占卜师，占卜师当晚就不会醒；僧侣先保护了共情者，之后恶魔攻击共情者就杀不死。
5. 醉酒、中毒的玩家照常唤醒、照常让他用能力，只是能力没有效果。
6. 夜间手势：轻拍两下肩膀或膝盖 = 睁眼；手遮眼 = 闭眼；点头 = 是；摇头 = 否；拇指朝上 = 善良；拇指朝下 = 邪恶；手指比数字（拇指和其他指尖相对表示 0）；指向某人 = 那名玩家；展示角色标记或在角色列表上指出 = 某个角色。
7. 玩家选择目标时，说书人走过去用手指竖直指向被选的人确认，双方点头才算数。

### 1.4 黎明

1. 到黎明后等 5～10 秒，再让所有人睁眼（防止玩家推断出谁是最后一个行动的）。
2. 公布这个夜晚**相对黄昏**生死状态有变化的玩家：谁死了、谁复活了。**不说死因**。没人死也要说“昨晚无人死亡”，同样不说原因。
3. 死亡要立刻公布，免得死者喊出“我昨晚没醒”来自证身份。

### 1.5 白天

1. 玩家自由交谈：可以公聊、耳语、离座私聊（尽量别走出座位围成的圈），可以撒谎，也可以沉默。善良玩家也可以撒谎。
2. 线上游戏私聊时，要告诉所有人谁在和谁私聊。
3. **说书人不以任何形式参与玩家之间的聊天**（比如不能主动给邪恶玩家建群）。
4. 玩家可以随时私下找说书人问自己或别人角色的规则，新手还可以问策略建议。

### 1.6 提名与投票

1. 由说书人宣布进入提名环节，一般讨论 5～10 分钟后开始，可以按玩家意愿延长或缩短。开始提名时所有人回到原座位。
2. 听到提名后复述一遍（“小美提名道哥！”），表示已经受理。
3. **提名限制**：
   - 同一时间只能有一个提名在进行，这次投票结束前不能发起下一个。
   - 只有**存活**玩家能发起提名。**死亡玩家可以被提名**（多数时候不明智，但合法）。
   - **每名玩家每天只能发起一次提名，每名玩家每天只能被提名一次。**
   - 玩家可以提名自己。
   - 已经“即将被处决”的玩家，如果当天还没提名过，仍然可以提名别人。
4. 投票前给被提名者 10～30 秒辩护时间（可以更长）。
5. **计票**：说书人站在圈中间指向被提名者，从他开始顺时针转一圈逐人计数，最后回到被提名者本人（他的票最后算）。指到某人时他举着手，就算投了一票。大声数数。
6. **投票权**：
   - 存活玩家每天可以给任意多个被提名者投票。
   - **死亡玩家在余下的整局游戏里只有一票（幽灵票）**。用掉后移除他的投票标记，之后不能再投。
   - 存活玩家和死亡玩家的票都算一票，没有加权。
7. **投票成功的条件（两条同时满足）**：
   - 票数 **≥ 存活玩家人数的一半**（即存活人数除以 2 向上取整）。死人的票同样计入，门槛只按存活人数算。例：6 人存活、4 人死亡，3 票就够。
   - 票数 **多于** 当天所有其他被提名者的票数（不能并列最多）。
   满足后，这名玩家进入“即将被处决”状态，后面的人只有票数更多才能取代他。
8. **平票**：如果某人的票数等于当前“即将被处决”者的票数，两人都不会被处决，台上清空；之后的被提名者必须**超过**这个平票票数，才能成为“即将被处决”。
9. 提名差不多了，或者没人再提名，说书人站到中间喊“最后一次提名！3…2…1…”，没人提名就结束提名阶段。

### 1.7 处决

1. 提名结束后，处决当前“即将被处决”的玩家，宣布他死亡；如果因为某种效果没死，就宣布“被处决但没有死亡”。
2. **每个白天最多处决一次**，处决后白天立即结束。
3. **不是每天都必须处决**：没人提名、票数不够、最高票平票，当天都无人被处决。
4. 处决和死亡是两回事：被处决的人可能不死；同一个人可以被处决多次；已死亡的玩家也能被处决（仍然占用当天唯一的一次处决）。
5. **已经死亡的玩家不会再死一次**（恶魔攻击一个死人，什么都不会发生，也没人知道这件事）。
6. 死亡玩家的规则：
   - 魔典里给他放帷幕标记；城镇广场上把他的生命标记翻到暗面，并放一枚投票标记。
   - 立即失去角色能力，能力造成的持续效果全部结束（能力写了“即使你已死亡”或在死亡时触发的除外）。夜里不再唤醒他。
   - 不能发起提名，只剩一票。
   - 仍要在夜里闭眼，仍可以随便说话。
   - 和自己的阵营一起胜利或失败。
   - **角色不公开**。

### 1.8 黄昏（入夜）

1. 处决结算完后，花大约 30 秒整理魔典，摆好提示标记和夜晚标记，然后宣布白天结束，让所有人闭眼。
2. 黄昏是夜晚的起点，在所有人闭眼之后。“持续到黄昏”的效果在这时结束。
3. 猎手、造谣者、杂耍艺人这类“在白天”使用的能力，最好在处决前用。处决后、闭眼前还能不能用，由说书人决定；说书人可以处决完就直接入夜，闭眼之后再想用就晚了。
4. 第一个白天结束后，夜晚顺序表换成“其他夜晚”那一面。

### 1.9 胜负条件

1. **善良获胜：所有恶魔都死亡。**（红唇女郎这类角色可能在恶魔死后接任，游戏继续，善良玩家不会知道发生了什么。）
2. **邪恶获胜：场上只剩两名存活玩家。**（可以是恶魔夜里杀人，也可以是白天处决错了人。）
3. 两个阵营同时达成胜利条件时，**善良获胜**（比如恶魔死后只剩两人存活）。
4. 阵营获胜时，该阵营所有玩家无论生死都获胜；没有平局。
5. 存活玩家在三人及以上时游戏继续。
6. 如果某一方已经稳赢，说书人可以提前宣布结束（见 8.2）。

## 2. 术语

- **中毒**：玩家失去能力，但自己以为还有能力，说书人也装作他有能力。信息类能力可以给他错误信息。他不会知道自己中毒。反义词是“健康”。
- **醉酒**：效果和中毒相同（失去能力、不知情、可以拿错误信息），只是来源不同。反义词是“清醒”。醉酒和中毒可以同时存在，**不会互相抵消**。
- **失去能力**：死亡、醉酒、中毒都会让玩家立刻失去能力，能力造成的持续效果随之中止；从醉酒或中毒中恢复后，能力和持续效果重新生效。失效期间用掉的能力就浪费了，恢复后也不会补上效果。
- **拥有能力**：存活、清醒、健康的角色才拥有能力（死后仍生效的能力除外）。
- **登记 / 误登记**（原文叫“被当作”）：被当作某个角色或阵营的玩家，在规则和其他能力的判断里就按那个角色或阵营处理，但他的真实阵营和能力不变。比如善良玩家被当作邪恶，仍随善良阵营获胜。陌客、间谍这类能力写的是“可能”被当作，由说书人每次单独决定，不是必须误登记，前后也可以不一样。
- **正确信息**：真实的陈述、手势或角色标记。**说书人给出的游戏规则永远必须正确**，对醉酒、中毒的玩家也一样。
- **错误信息**：错误的陈述、手势或角色标记。只有两种情况可以给：使用能力的玩家醉酒或中毒；被查验的玩家被当作别的角色或阵营。
- **存活**：尚未死亡。存活玩家有能力，可以提名，可以给任意多个提名投票。
- **死亡**：已经死亡。没有能力（个别例外），不能提名，整局只剩一票，仍可发言，仍随阵营胜负。
- **选择**：能力描述里出现“选择”，就由该玩家做决定；**没有出现“选择”，就由说书人决定**（比如“每个夜晚会有一名玩家中毒”由说书人选人）。同理，洗衣妇、图书管理员、调查员看哪几个人，是说书人定的，不是玩家选的。
- **可能**：某件事“可能”发生，代表由说书人决定它发不发生。
- **在场 / 不在场**：在场 = 本局游戏中存在的角色（不论死活）。不在场 = 列在角色列表上、但本局没有的角色。恶魔的三个伪装就是从不在场的善良角色里给。
- **疯狂**：玩家被要求“疯狂”地证明某件事，就要真诚、努力地让其他人相信这件事；如果被要求不要疯狂证明某事，就不能去说服别人。由说书人判断他有没有做到，并按能力描述奖励或惩罚。疯狂是让善良玩家**有意识地**传播错误信息（醉酒和中毒则是让他们无意中传播）。**这两个剧本里没有造成疯狂的角色**，这里只作了解。
- **处决**：白天集体投票杀死一名玩家，每天最多一次，也可以没有。
- **即将被处决**：当天票数达到门槛、且票数最多（无并列）的那名玩家。
- **以为**：玩家以为自己是另一个角色（比如酒鬼拿到镇民标记，疯子以为自己是恶魔）。说书人要配合演，让他相信下去。
- **邻近的玩家 / 邻近的存活玩家**：顺时针、逆时针方向各自最近的那名玩家；说“存活”时，中间的死者跳过不算。
- **每个夜晚\***：除首个夜晚以外的每个夜晚。
- **在你的首个夜晚得知**：首夜得知信息；如果中途才变成这个角色，就在变成的那一刻（尽快）得知。
- **每局游戏限一次**：只能用一次。醉酒、中毒时用掉也算用掉；没用就死了，机会作废。复活或变成新角色后重新获得。
- **黄昏 / 黎明**：夜晚的开始点（所有人闭眼后）和结束点（白天开始前）。
- **公开 / 私下**：大多数玩家和说书人都知道 / 只有两名玩家之间或玩家与说书人之间知道。
- **状态**：角色、阵营、生死、醉酒、中毒、疯狂。**状态绑定的是玩家，不是角色**，各状态之间互相独立。

## 3. 隐性规则（规则书没写明、但按规则处理的默认共识）

1. **同时触发由说书人定顺序**：多个能力同时满足触发条件时，由说书人决定结算顺序，但要尽量选**更有趣而不是更混乱**的顺序。
2. **“不能”最大**：一个能力允许某件事、另一个能力禁止它时，永远是“不能”生效。例如刺客的攻击可以杀死受保护的玩家。
3. **自我 / 循环中毒、醉酒**：让自己中毒的能力生效后，这名玩家只保留“让自己中毒”这条效果和它的结束条件，其余能力全部失去。例如普卡攻击自己会永久中毒（因为没有结束条件）。多名玩家之间循环中毒、醉酒，处理方法相同：大家一起失效，到各自结束条件时再分别解除。
4. **角色唯一**：同一个角色在场上同时最多只有一个。能力改变角色时，如果没有明确说明，不会打破这条规则。
5. **死亡有先后**：不存在多名玩家“同一时刻”死亡，所有死亡都按某个顺序一个接一个发生。恶魔造成的多次死亡按攻击顺序结算。
6. **夜晚行动过时不候**：某个角色当晚的行动已经开始结算，那么当晚新产生的同一角色（或获得这个能力的角色）当晚不再行动。例：小恶魔自杀传位给爪牙，新小恶魔当晚不再杀人。
7. **角色详解不考虑中毒、醉酒和特殊互动**：角色页只写基本运作和常见案例。涉及中毒、醉酒或复杂互动时，不要死套“运作方式”，要按能力本身的逻辑和游戏理念去推。

## 4. 重要细节

### 4.1 规则特例
- **规则没说“不能”，就可以**：可以提名自己、给自己投票；恶魔可以攻击死人；善良玩家可以撒谎；“任意玩家”包括自己和死人；死人可以说话。但死人不能提名、只有一票，因为规则写了。
- **可以做，不代表应该做**：每个决定都要让游戏更好玩，而不是让说书人自己开心（见 6.4）。
- **说书人的话就是规则**：拿不准的措辞或互动，说书人有最终解释权。定下处理方式后告诉玩家，并在整局里保持一致。
- **角色能力与核心规则冲突时，以角色能力为准。**

### 4.2 角色能力
1. **能力立即生效**（见 1.3）。
2. **只告诉玩家他的能力应该得知的信息，秘密就是秘密**：红唇女郎接任恶魔、猎手开枪没打中、僧侣保护了谁，其他人都不知道。夜里死了人，大家只知道谁死了，不知道怎么死的。
3. **死亡、中毒、醉酒的瞬间立即失去能力**，持续效果同时中止。例：投毒者毒了猎手，同一晚稍后投毒者死了，猎手立刻不再中毒。恢复清醒或健康后，持续效果继续生效；失效期间的那次使用不会补上。
4. **死后保留能力**：注意“即使你已死亡”“当你死亡时”这类字样（比如守鸦人死时会醒来）。这类能力在醉酒、中毒时同样失效。
5. **能力里没有“选择”，就由说书人选。**
6. **玩家用错能力要立刻提醒**：白天直接说，夜里摇头让他重选。例如僧侣不能选自己；侍女必须选存活玩家。
7. **复活、变化或交换角色，等于拿到新角色**：
   - 立即获得新能力，失去旧能力和它的持续效果。“每局限一次”的能力即使别人用过，也可以再用一次；只在首夜生效的能力，在变化当晚生效。
   - 中途变成爪牙或恶魔，**不会**得知队友是谁，也**不会**拿到三个伪装（这些属于开局信息，不是能力）。
   - 方括号能力不触发。
8. **能力的触发时机可以不同于夜晚顺序表**：
   - 中途产生的“首个夜晚”角色要尽快结算进场能力，但大多数信息类能力应该放在所有致死效果之后。
   - “当你死亡时”类能力在夜晚顺序表上的位置，只是**最晚**结算点。也可以一死就立刻结算。即使已经过了顺序表上的位置，死亡时也要照常触发。
   - 按角色能力描述结算，比死守顺序表更重要。

### 4.3 状态
- 生死、阵营、角色、醉酒、中毒互相独立。善良玩家变成邪恶角色，阵营不会跟着变；醉酒的玩家换了角色，仍然醉酒。
- 阵营可能在游戏中改变（镇民可以变邪恶，恶魔也可以变善良）。阵营或角色一旦变化，要第一时间秘密告诉本人（展示“你是”加新角色标记或阵营手势）。
- **得知自己角色或阵营的变化不算“获得信息”**，不受醉酒、中毒影响，必须如实告知（酒鬼、疯子这类本来就设计成不知道自己真实身份的角色除外）。
- **不要告诉玩家他醉酒或中毒了**，让他照常行动。偶尔可以给出暗示（比如没人宣称镇长时，给送葬者看镇长），但这种机会很少。
- 醉酒、中毒的玩家**可以**拿到错误信息，不是一定要给，**通常应该给**。
- **对醉酒、中毒玩家使用的能力照常生效**：共情者能正确判断邻座醉酒玩家的阵营，占卜师能正确查出中毒的恶魔。
- “每局限一次”的能力在醉酒、中毒时用掉，就再也不能用。
- 能力在清醒健康时触发就正常生效，此前醉酒、中毒不影响它的前提条件（比如杂耍艺人白天猜的时候醉了，只要夜里醒来时清醒，就得到正确结果）。
- 小贴士：留意邪恶玩家的谎言，在规则允许的范围内用醉酒、中毒的信息去支撑这些谎言。一般来说，醉酒、中毒的效果应该尽量对中招的玩家不利。

## 6. 说书人的理念与建议

### 6.1 选角色、配板子

- **信息与混淆的对抗**：善良的强项是信息，邪恶的强项是混淆信息、或者让游戏更快进入最后一天。知道全部信息的爪牙（间谍）并不比让谎言变得可信的爪牙（投毒者）更强。
- **单个角色本来就不平衡**：邪恶角色单个比善良角色强，因为邪恶人少，而且每天都可能输，善良只会在最后一天输。不要追求善恶角色一一对等。
- **剧本整体胜率**：《暗流涌动》近 600 局记录中善恶胜率只差约 1%，非常平衡。《黯月初升》邪恶胜率略高，新手善良玩家还不熟悉这个剧本的策略，老手局会逐渐接近 50/50。
- **配置会影响难度，但很少决定胜负**：比如酒鬼和投毒者同时在场，比间谍加管家对善良更难。但实践中，配置选择很难单独决定一局的结果；说书人只有犯大错或故意破坏，才会真正让游戏失衡。
- **注意“下限能力”**：大多数角色什么都不做也能贡献一点。但送葬者、守鸦人对新手来说下限偏低（容易被早杀或乱选），占卜师下限很高（新手也可能靠运气拿到决胜信息）。新手局要考虑这一点。
- **外来者的平衡**：外来者给善良多一张票、让邪恶多杀一个人，还带来可信度（只有一个外来者且他公开时，善良优势很大）。外来者的负面能力就是用来抵消这些好处的。
- **人数**：《黯月初升》不建议少于 7 人开（沙巴洛斯、莽夫等在 5～6 人局对某一方很不公平）。
- **偶尔会出现看起来失衡的局面**（典型例子：共情者正好坐在两个邪恶玩家中间），官方剧本里很少发生，发生时落后的一方也往往能打得很精彩，不用刻意修正。
- **给恶魔的三个伪装不要包含酒鬼以为的那个角色**：它虽然不在场，但对恶魔伪装没帮助，也不有趣。
- **选你能主持好的配置**：有趣、互动好、自己处理得来，优先于“看起来很强”。

### 6.2 给醉酒、中毒玩家的假信息

- **通常就该给假信息**：醉酒、中毒的意义就在于让善良玩家在不知情时传播错误信息。不给的话，投毒、醉酒就形同虚设。
- **配合邪恶玩家的伪装**：先听清邪恶玩家声称自己是什么，再让假信息支撑这个说法。例：醉酒的守鸦人查一个声称是镇长的男爵，就给他看镇长标记；醉酒的守鸦人查一个善良玩家，就给他看一个邪恶角色标记。总的原则是让假信息对中招的玩家尽量不利。
- **假信息要像真信息**：要符合该能力的正常形式（共情者给 0～2 的数字，送葬者给一个角色标记，等等）。玩家自以为能力正常，所以信息必须看起来能用。
- **假信息只能来自合法来源**：只能因为醉酒、中毒、误登记而错。可靠的信息是善良取胜的关键；如果善良的推理建立在一个**没有任何办法发现**的错误上，他们就是在瞎猜，没人觉得好玩。所以不要凭空制造错误。
- **不要骗清醒健康的玩家**：例如给调查员准备的提示标记放在陌客身上，但陌客在调查员醒来前被下了毒、已经不能被当作爪牙，那就必须重新放标记，给调查员真信息。
- **夜晚前先想好**：在准备夜晚时就决定好今晚要给酒鬼、中毒者什么假信息，要展示哪三个伪装，保证夜晚节奏流畅。
- **规则永远真实**：即使他醉酒、中毒，回答规则问题也必须正确。玩家要能完全信任说书人对规则的解释。
- **不要把游戏搞崩**：不要给出能直接锁定恶魔的信息（原文举的是其他剧本博学者的例子：直接给“某某是恶魔”这种能被马上验证的信息，是新手说书人的错误）。也不要所有信息都指向同一个结论、最后再靠说书人的选择收割（原文例：所有信息都确认镇长是好人，最后一晚恶魔攻击镇长时，说书人却让投毒者替死）。这两种都会让游戏失衡。

### 6.3 什么时候帮善良，什么时候帮邪恶

- **目标是打到最后一天**：《染》最刺激的时刻，是场上只剩三到四名玩家、一次处决决定胜负的时候。说书人要设法让游戏走到这一步。
- **暗中帮弱势的一方**：不能改规则，但在说书人有选择权的地方，可以给弱势方一点“无形的运气”。
  - 邪恶碾压善良时：某晚给醉酒的共情者真信息；让送葬者看到被处决的间谍就是间谍；镇长被攻击时，让一名爪牙替他死，而不是镇民。
  - 善良快要赢时：仔细想好给醉酒、中毒的镇民什么信息，在恰当的时机给出错误信息，可能扭转局势。
- **不知道该帮谁时：要么谁都不帮，要么帮邪恶**。善良只要一次好运就能赢，邪恶却需要每天都走运。
- **平时要帮邪恶圆谎**：邪恶玩家非常依赖说书人让他们的谎言显得真实。
  - 小恶魔声称是猎手并“开枪”，要配合他演，看起来像真猎手开枪没打中。
  - 间谍声称是占卜师、被守鸦人查到时，可以让间谍被当作占卜师。
  - 邪恶玩家声称是贞洁者并被提名时，可以假装往魔典里放“失去能力”标记。
  - 善良角色用完能力时你会移动提示标记，邪恶玩家假装用同一个能力时，也要假装移动，别让老玩家从你的手部动作看出谁在伪装。
- **绝不能用规则直接决定胜负**：比如为了结束游戏而杀死修补匠，或者镇长被攻击时让场上最后一个邪恶玩家替死，这都很不公平。尽量让玩家觉得，游戏里最精彩的部分都来自他们自己的行动和选择。
- **劣势方只要还有一丝希望，就让游戏继续**（见 8.2）。
- **游戏的天然平衡**：双方都乱打时胜率约 50/50，打得好的一方能把胜率提到 70%～90%。说书人通常只需要帮邪恶伪装、认真主持；局面失衡时，多半是因为某一方打得好，这正是游戏该有的样子。
- **犯了错不要“补偿”另一方**：补偿很难拿捏，善良玩家还可能从补偿反推出你犯了什么错（见 6.5）。

### 6.4 说书人做选择的优先级

1. **规则第一，不破坏规则**：不能随意决定生死，不能中途偷改爪牙、恶魔数量，不能偷偷去掉恶魔或加个酒鬼。整套角色足够多，想做的“疯狂操作”总能找到合法的角色来实现。
2. **有趣优先于混乱**：同时触发、互动不明确时，选更有趣、更容易理解的处理方式。
3. **理念优先于死扣字面**：理解设计意图。爪牙、外来者的能力本来就应该对善良不利。所以不要借陌客、间谍的误登记，让邪恶能力在设计上本该生效的地方失效（“可能”被当作意味着说书人有权不这么做）。反过来，如果陌客本来就是邪恶阵营，小恶魔自杀时把他当作爪牙接任也合理。
4. **机制问题和社交问题要分开**：机制问题有标准答案；社交问题（玩家行为、氛围）没有固定答案，要看场合和玩家灵活处理。
5. **让玩家自己做决定**：占卜师每晚查同一个人、僧侣保护死人、恶魔杀已经跳身份的守鸦人、投毒者毒恶魔……玩家可能另有打算（测试自己是否醉酒、凑镇长三人局、假装是士兵等）。不要强迫玩家接受你认为的最优解。
6. **“可以但不建议”的事不做**（本组合相关的条目）：
   - 恶魔信息里，不要把酒鬼以为的角色当成不在场角色给恶魔。
   - 镇长：不要频繁让替死落到一个本来就死不了的玩家身上。
   - 陌客：不要在爪牙信息、恶魔信息阶段把他当作爪牙或恶魔（不要让真爪牙看到两个“恶魔”、不要让他和爪牙一起睁眼）；不要在小恶魔自杀时把（善良的）陌客当作爪牙让他接任；不要在陌客死时把他当作恶魔，让红唇女郎变成那个恶魔；不要把陌客设为占卜师的干扰项；间谍查看魔典时，不要把陌客的标记换成邪恶角色标记；不要对教父隐瞒陌客在场，陌客死亡时也应该当作外来者，正常触发教父。**没有其他恶魔存活时把陌客当作恶魔让游戏继续，是规则就不允许的。**
   - 酒鬼：不要让他以为的角色和某个在场镇民相同。
   - 间谍：不要把间谍设为占卜师的干扰项；间谍查看魔典时，不要把间谍自己的标记换成善良标记；不要在爪牙信息、恶魔信息阶段把间谍当作善良，让他不参与互认；小恶魔自杀时，不要把间谍当作善良角色，让他接不了任而直接结束游戏。
   - 祖母：不要让祖母成为她自己的孙子。
   - 教授：不要允许他夜里把存活玩家挨个点一遍来试谁死了（只有在他醒来前复活的人，才提醒他换目标）。
   - 造谣者：不要让造谣者的能力杀死一名无法死亡的玩家。
7. **说书人是来服务玩家的**：别只顾自己开心，比如把迷惑的善良玩家骗成以为自己是邪恶的；能给出有趣、独特的信息时，就不要给完全没用的信息。每个决定都应该让大家更开心。通常这意味着给善良制造尽可能多的混乱，但公平同样重要。
8. **允许有创意的玩法**：邪恶玩家用手机互发消息、善良玩家伪装自己、玩家私聊后对外说完全不同的话，都可以。不能接受的是违反游戏规则、欺凌羞辱，以及把游戏和游戏外的利益挂钩（比如用真钱买票）。

### 6.5 常见误判纠正（设计师总结的国内玩家误解，只保留和本组合相关的）

- 占卜师的干扰项**只**干扰占卜师，不影响其他人的信息。
- 镇长的替死能力**不限一局一次**；替死的人**不限于士兵**，也**不需要**征求任何玩家同意。
- 陌客、间谍**不是必须**误登记，每次都可以单独决定，前后可以不同。
- 存活玩家和死亡玩家的票**都算一票**。
- 提名、被提名的限制是**每天**一次，不是每局一次；投票不限次数（死人除外）。
- **不是每天都必须处决。**
- 洗衣妇、图书管理员、调查员、厨师等角色查看谁，**由说书人决定**，不是玩家选。
- 醉酒、中毒的守鸦人死在夜里**仍然会被唤醒**，只是可能拿到错误信息。
- 醉酒、中毒的玩家**照常在夜里醒来**。
- 本组合里**只有小恶魔**能靠自杀把恶魔身份传给爪牙，其他恶魔没有这个能力。
- “疯狂”地证明自己是某角色，不等于“像那个角色一样玩”，而是要努力让别人相信。

### 6.6 节奏与主持

**时间节奏**
- 白天讨论 5～10 分钟后开始提名，可以按玩家意愿调整。
- 辩护 10～30 秒。
- 处决后用约 30 秒准备夜晚，再让大家闭眼。
- 黎明前等 5～10 秒再让大家睁眼。
- 夜里放松、慢慢来，别被催。夜里越从容，犯的错越少。

**公开信息**
- 宣布重要事情（计票、“最后一次提名 3…2…1”）时，站到圈中间，确保所有人听得见、看得见。
- 死亡立即公布，不说死因；没人死也要宣布。
- 被提名、投票结果要大声复述。
- 宣布胜利时稍作停顿、用隆重的语气，让获胜方尽情庆祝。

**处理玩家提问**
- 尽量**私下**回答。私下可以说得更直接。
- 公开回答时，**用玩家的名字，不用角色名**，也不要用“昨晚的一根手指”这类会暴露角色的说法。比如有人公开问“僧侣一晚能选几个人”，直接回答就等于确认了他是僧侣。
- 说书人是中立的，职责是帮玩家理解规则、玩得开心。新手可以私下问策略建议。
- 夜里玩家醒来不知道该做什么时，指给他看角色列表上自己的能力描述。

**防止信息泄露**
- 夜里刻意多走动，不要每晚第一件事都走到同一个位置。
- 叫醒玩家时轻拍、不出声。
- 邪恶玩家假装用能力时，也要假装摆弄标记。
- 线上私聊要告知所有人。

**犯错时**
- 继续游戏，把后面主持好。要尽快告诉大家你犯了个错，但**不说是什么错**。
- 例外：夜里忘了叫醒某人，可以早上让大家重新闭眼单独叫醒他，或者私聊补上他的能力。
- 因为失误让某一方赢了，就向输的一方道歉；受益的一方仍然输了，就好好恭喜赢家。

**主持氛围**
- 消极行为（大喊大叫、胁迫、情绪勒索、人身攻击、假装受伤博同情）要私下劝导，强调问题在行为本身，不在这个人。屡教不改的不让他继续参加。
- 照顾害羞的玩家：隔一段时间给他一个说话的机会（他被提名时最合适：“你被提名了，有什么想说的吗？”），但永远不强迫他说话。不要单独让健谈的玩家闭嘴；需要安静时让所有人一起安静。
- 注意敏感话题（死亡、两性、性别、玄学等），必要时用自制角色列表剔除让人不适的角色。
- 可以讲一点故事：开场铺一句背景（“这是一个雷雨交加的夜晚……”）；处决前问对方“你想以什么方式死去？”，再帮他补一点细节。要短、轻松、有趣，不要血腥露骨，不要拿两性、隐私开玩笑。不擅长就不讲，沉默的说书人也能主持好一局。
- 好的说书人会让玩家对彼此投入感情：描述的是“城镇广场上发生了什么”，不是“魔典里的机制”；称赞玩家精彩的发言、指控和辩护；时不时私下问玩家玩得开不开心、心里怀疑谁。说书人自己玩得投入，玩家也会投入。
- 尽量让玩家待在座位围成的圈里，防止老玩家扎堆、新玩家落单；同时鼓励大家离座和圈对面的人私聊。

## 7. 夜晚行动顺序（暗流涌动 + 黯月初升）

按官方总表的顺序，只摘出这两个剧本的角色，混合排列。只唤醒今晚确实要行动的角色；不在场或当晚不满足条件的直接跳过。官方说明：这份总表对部分角色做了顺序优化，说书人可以按原剧本的顺序表执行，也可以按这里的推荐顺序执行。

### 7.1 首个夜晚

1. **黄昏**：确认所有玩家都闭上了眼睛。
2. **爪牙信息**（7 人及以上）：唤醒所有爪牙，展示“他是恶魔”并指向恶魔。
3. **疯子**：唤醒疯子，向他提供恶魔信息（他以为自己是恶魔）；需要时让他先于真恶魔做恶魔的行动。之后在恶魔信息环节，告诉真恶魔疯子的相关信息。
4. **恶魔信息**（7 人及以上）：唤醒恶魔，展示“他们是你的爪牙”并指向所有爪牙；展示“这些角色不在场”，再给三个不在场的善良角色。
5. **水手**：让他选一名玩家，决定两人中谁醉酒。
6. **投毒者**：让他选一名玩家，该玩家中毒。
7. **侍臣**：他可以摇头不用能力，或选择角色列表上的一个角色，对应玩家醉酒。
8. **教父**：展示在场的外来者角色标记。
9. **魔鬼代言人**：让他选一名玩家，该玩家被处决时不会死。
10. **普卡**：让他选一名玩家，该玩家中毒。
11. **洗衣妇**：指向两名玩家，展示一个镇民标记。
12. **图书管理员**：指向两名玩家，展示一个外来者标记。
13. **调查员**：指向两名玩家，展示一个爪牙标记。
14. **厨师**：用手势告诉他有几对相邻的邪恶玩家。
15. **共情者**：用手势告诉他邻近的两名存活玩家里有几个邪恶。
16. **占卜师**：让他选两名玩家，点头或摇头表示其中有没有恶魔。
17. **管家**：让他选一名除自己以外的玩家作为主人。
18. **祖母**：指向一名善良玩家（孙子），展示他的角色标记。
19. **间谍**：让他查看魔典。
20. **侍女**：让她选两名除自己以外的存活玩家，告诉她其中有几人今晚因自己的能力醒来过。
21. **黎明**：等几秒，让所有玩家睁眼。

### 7.2 其他夜晚

1. **黄昏**：确认所有玩家都闭上了眼睛。“持续到黄昏”的效果结束。
2. **水手**：让他选一名玩家，决定两人中谁醉酒。
3. **投毒者**：让他选一名玩家，该玩家中毒。
4. **旅店老板**：让他选两名玩家，这两人今晚不会死，并决定其中谁醉酒。
5. **侍臣**：如果还没用过能力，他可以摇头不用，或选一个角色，对应玩家醉酒。
6. **赌徒**：让他猜一名玩家的角色，猜错他就死亡。
7. **僧侣**：让他选一名除自己以外的玩家，该玩家今晚免受恶魔的负面效果。
8. **魔鬼代言人**：让他选一名与上一晚不同的玩家，该玩家被处决时不会死。
9. **红唇女郎**：如果她的能力已触发，唤醒她，告诉她变成了哪个恶魔。
10. **疯子**：如果他以为的恶魔今晚要行动，就唤醒他，让他按恶魔的方式行动。
11. **驱魔人**：让他选一名与上一晚不同的玩家；如果选中恶魔，在驱魔人入睡后告诉恶魔谁是驱魔人。
12. **小恶魔**：让他攻击一名玩家。如果他成功自杀，在他入睡后告诉一名爪牙他变成了小恶魔。
13. **僵怖**：如果今天白天无人死亡，唤醒他攻击一名玩家。
14. **普卡**：让他选一名玩家，该玩家中毒；上一个被普卡毒的玩家死亡。
15. **沙巴洛斯**：先决定上一晚被他选中的玩家是否被反刍，然后让他攻击两名玩家。
16. **珀**：他可以攻击一名玩家或不攻击；如果上次选择了不攻击，这次必须攻击三名玩家。
17. **刺客**：如果还没用过能力，他可以摇头不用，或攻击一名玩家。
18. **教父**：如果今天白天有外来者死亡，唤醒他攻击一名玩家。
19. **造谣者**：如果他今天白天的声明是真的，一名玩家死亡。
20. **修补匠**：夜里任何时候都可以决定让他死，这里只是提醒别忘了。
21. **月之子**：如果月之子今天白天用能力选中了一名善良玩家，那名玩家死亡。
22. **祖母**：如果恶魔杀死了孙子，祖母死亡。
23. **守鸦人**：如果他在夜里死亡，唤醒他选一名玩家，展示该玩家的角色标记。
24. **教授**：如果还没用过能力、且有玩家死亡，他可以摇头不用，或选一名已死亡的玩家；如果是镇民，该玩家复活。
25. *（信息类角色行动开始：中途变成首夜信息角色、需要补拿首夜信息的，在这里结算；多项同时触发时由说书人定顺序。）*
26. **共情者**：用手势告诉他邻近的两名存活玩家里有几个邪恶。
27. **占卜师**：让他选两名玩家，点头或摇头表示其中有没有恶魔。
28. **管家**：让他选一名除自己以外的玩家作为主人。
29. **送葬者**：如果今天白天有人死于处决，展示那名玩家的角色标记。
30. **间谍**：让他查看魔典。
31. **侍女**：让她选两名除自己以外的存活玩家，告诉她其中有几人今晚因自己的能力醒来过。
32. **黎明**：等几秒，让所有玩家睁眼。宣布黄昏时还活着、现在死了的玩家死亡，以及黄昏时已死、现在复活的玩家复活。

## 8. 说书人惯例（原文中出现的“残局 / 打到最后”类说法）

原文**没有**出现“F3”“决赛圈”这类字样。和“打到最后几人”有关的说法如下。

### 8.1 打到最后一天，三到四人存活时最刺激
- 出处：《给说书人的建议》第二部分第 6 条“设法让游戏进行到最后一天”。
- 原意：最刺激的时刻，是场上只剩三到四名玩家、一次关键处决就能定胜负的时候，在这时结束的游戏最有戏剧性。为此说书人要在有选择权的地方暗中帮弱势方；不知道帮谁时，就谁都不帮或帮邪恶；但不能利用规则直接让某一方获胜。（具体做法见 6.3。）

### 8.2 四人存活时可以提前结束游戏
- 出处：《给说书人的建议》第一部分第 1 条“当一个阵营已经能确定获胜时，你就可以提前结束游戏”。
- 原意：
  - 所有存活玩家都是邪恶时，恶魔已经不可能被提名，可以直接宣布邪恶获胜。
  - 通常情况下，场上剩 4 人、善良处决了一个非恶魔玩家后，剩下 3 人，恶魔当晚再杀一人就会结束，可以直接宣布邪恶获胜。
  - 但如果僧侣、士兵这类能让恶魔当晚杀不死人的角色还活着，游戏就要继续，因为恶魔仍可能在下一个白天被处决。
  - 提前结束前要仔细判断：劣势方只要还有一点点赢的可能，就要让游戏继续。

### 8.3 原文里的“F4”指的不是“最后四人”
- 出处：《设计师的平衡天书》“战术的平衡”一节。
- 原文提到玩家口中的“我们总是立即杀死 F4”和开局“F4 请先说话”。从上下文看（设计师作为恶魔假称自己是调查员，说“直到现在才透露我是 F4”），这里的 F4 是玩家对首夜四个信息角色（洗衣妇、图书管理员、调查员、厨师）的俗称，**不是**“决赛圈四人”。
- 设计师的观点：不存在固定最优解。总是马上处决 F4 会让最后一天活着的邪恶玩家更多，善良拿到了信息却丢了票，老手邪恶还会专门伪装 F4 来利用这个习惯。说书人不必鼓励或配合这类“固定套路”。

### 8.4 死人投票是平衡机制
- 出处：《设计师的平衡天书》“马太效应问题”一节。
- 原意：死亡玩家保留一票，防止领先的一方滚雪球。即便如此，如果最后只剩邪恶玩家活着，那是邪恶打得好，提前获胜是他们应得的。

### 8.5 玩家永远不该陷入必输的“坐牢”局面
- 出处：《设计师的平衡天书》“强度的波动”一节。
- 原意：游戏的设计目标是让玩家永远不会陷入明知必输、只能干等结束的境地。说书人做判断时应维护这一点，配合 8.1、8.2 使用：劣势方还有机会，就不提前结束；某一方已经稳赢，就别拖。
