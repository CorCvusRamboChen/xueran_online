# 黯月初升（Bad Moon Rising）说书人参考

《黯月初升》难度为**中等**，推荐给积极主动、善于合作、不怕死的玩家。它是一场"死亡盛宴"：恶魔每晚可能杀不止一人，爪牙（刺客、教父）也会杀人，善良方自己的能力（赌徒、造谣者、月之子、修补匠、祖母）还会误杀队友；同时场上又有大量保命手段（水手、旅店老板、茶艺师、弄臣、和平主义者、魔鬼代言人、教授复活、沙巴洛斯反刍）。
- **善良方**：消极就拿不到信息。茶艺师、和平主义者要靠处决来验证，赌徒、造谣者要冒死换信息。必须盯紧每一个夜晚谁死了、为什么死，借此反推是哪个恶魔、哪些爪牙在场。否则可能在还剩 4–6 人存活时突然输掉（多刀恶魔、主谋）。
- **邪恶方**：看起来很强，但要精确使用能力。恶魔常常要伪装成"另一种恶魔"，避开驱魔人、侍臣的针对，有时还要故意不杀人来佐证说法。要分清该杀谁、不该杀谁（茶艺师的邻座、弄臣）。爪牙要抓准时机：刺客何时出刀、魔鬼代言人保谁、主谋能不能藏到最后。

> 约定：能力文字里的 "*" 表示"首个夜晚除外"。下文"醉酒中毒"都指"醉酒或中毒"，二者效果相同。"宣布被处决但依然存活"时一律不说原因。

## 二、夜晚顺序

> 醉酒中毒的玩家照常唤醒、照常走流程。被唤醒的角色死了就跳过（另有说明的除外）。

### 首个夜晚

1. **黄昏**：确认所有玩家都闭上了眼睛。部分旅行者和传奇角色在这时行动。
2. **爪牙信息**：如果有七名或更多玩家，唤醒所有爪牙，展示"他是恶魔"信息标记，指向恶魔。
3. **疯子**：如果有七名或更多玩家，唤醒疯子，展示"他们是你的爪牙"信息标记，指向任意几名玩家（人数等于在场爪牙数）。再展示"这些角色不在场"信息标记，给他看三个善良角色，然后让疯子入睡。接着唤醒恶魔，展示"你是"信息标记和恶魔角色标记，再展示"这名玩家是"信息标记和疯子角色标记，指向疯子玩家。
4. **恶魔信息**：如果有七名或更多玩家，唤醒恶魔，展示"他们是你的爪牙"信息标记，指向所有爪牙。再展示"这些角色不在场"信息标记，给他看三个不在场的善良角色。
5. **水手**：让水手选一名存活玩家。水手或那名玩家之一醉酒（说书人决定是谁）。
6. **侍臣**：侍臣可以选一个角色。如果选了，标记侍臣失去能力，并让该角色对应的玩家醉酒。之后的夜晚不再唤醒侍臣。
7. **教父**：给他看所有在场外来者的角色标记。
8. **魔鬼代言人**：让他选一名存活玩家，给那名玩家放"处决不死"标记。
9. **普卡**：让普卡选一名玩家，给那名玩家放"中毒"标记。
10. **祖母**：指向她的孙子，展示孙子的角色标记。
11. **侍女**：让侍女选除自己外的两名存活玩家，用手势告诉她其中有几人今晚因自身能力被唤醒过。
12. **黎明**：等几秒，让所有玩家睁眼。

### 其他夜晚

1. **黄昏**：确认所有玩家都闭上了眼睛。部分旅行者和传奇角色在这时行动。
2. **水手**：让水手选一名存活玩家。水手或那名玩家之一醉酒。
3. **旅店老板**：让旅店老板选两名玩家。这两人今晚不会死亡，其中一人醉酒。
4. **侍臣**：侍臣可以选一个角色。如果选了，标记侍臣失去能力，并让该角色对应的玩家醉酒。之后的夜晚不再唤醒侍臣。
5. **赌徒**：让赌徒选一名玩家和一个角色。猜错了就标记赌徒死亡。
6. **魔鬼代言人**：让他选一名存活玩家，不能是他上一夜选过的玩家，给那名玩家放"处决不死"标记。
7. **疯子**：按疯子以为的那种恶魔，做模拟恶魔行动所需的一切，然后让疯子入睡。唤醒真恶魔，展示疯子角色标记，指向疯子玩家，再指向疯子今晚的攻击目标。
8. **驱魔人**：让驱魔人选一名玩家，不能是他上一夜选过的玩家，然后让他入睡。如果他选中了恶魔：唤醒恶魔，展示"该角色的能力对你生效"信息标记和驱魔人角色标记，指向驱魔人玩家。
9. **僵怖**：如果今天白天没有人死亡，让僵怖选一名玩家，标记那名玩家死亡。
10. **普卡**：让普卡选一名玩家，标记中毒。然后上一个因普卡中毒的玩家死亡，随后恢复健康。
11. **沙巴洛斯**：先决定上一夜被沙巴洛斯选中、且现在已死亡的玩家中，要不要反刍一人；如果反刍，标记那名玩家复活。然后让沙巴洛斯选两名玩家，标记这两人死亡。
12. **珀**：珀可以选一名玩家；如果他上一次被唤醒时没有选任何人，这次让他选三名玩家。标记这些玩家死亡。
13. **刺客**：刺客可以选一名玩家。如果选了，标记那名玩家死亡，刺客失去能力，之后的夜晚不再唤醒刺客。
14. **教父**：如果今天白天有外来者死亡，让教父选一名玩家，标记那名玩家死亡。
15. **教授**：教授可以选一名死亡玩家。如果选了，标记教授失去能力；如果那名玩家是镇民，标记他复活。之后的夜晚不再唤醒教授。
16. **造谣者**：如果今天白天造谣者的公开声明为真，由说书人选一名玩家，标记死亡。
17. **修补匠**：修补匠可能死亡。如果说书人决定让他死，放死亡标记。
18. **月之子**：如果月之子今天白天触发了能力并选中一名善良玩家，那名玩家死亡，标记死亡。
19. **祖母**：如果孙子今晚被恶魔杀死，祖母一同死亡，标记祖母死亡。
20. **侍女**：让侍女选除自己外的两名存活玩家，用手势告诉她其中有几人今晚因自身能力被唤醒过。
21. **黎明**：等几秒，让所有玩家睁眼，并立即宣布有谁死亡。之后再宣布有谁复活（教授或沙巴洛斯造成的，不说原因）。

## 三、给新手说书人的推荐配置（八人游戏）

八人局标准是 5 镇民 / 1 外来者 / 1 爪牙 / 1 恶魔。可以挑一套，按自己的风格稍作修改。

### 配置 1：赌徒、教授、吟游诗人、和平主义者、弄臣、修补匠、刺客、沙巴洛斯

- 第一次主持《黯月初升》时用这套：本剧本最简洁、最直白的角色。
- **记住**：要由你把握三个时机：和平主义者什么时候救人、修补匠什么时候死、沙巴洛斯什么时候反刍。
- 吟游诗人和弄臣的能力自动触发，其余选择都交给玩家。

### 配置 2：赌徒、侍臣、侍女、祖母、修补匠、月之子、教父、僵怖

- 4 镇民 + 2 外来者：教父用了 [+1 外来者]。
- 善良方愿意冒险时，这局信息量爆炸。赌徒、侍臣、侍女、祖母拿信息很快，但要仔细整合，才能锁定难找的僵怖。
- 修补匠和月之子给恶魔提供了重要的掩护（额外死亡）。教父也会造成额外的夜晚死亡，玩家很难靠死亡人数判断是哪种恶魔。

### 配置 3：侍女、旅店老板、吟游诗人、驱魔人、弄臣、疯子、刺客、普卡

- 对邪恶方来说娱乐性很高：刺客和普卡都能杀死本来不会死的玩家。普卡毒到侍女、旅店老板、吟游诗人或驱魔人，都会给善良方毁灭性打击。
- 善良方可能从弄臣的死推断出普卡在场，也可以用旅店老板挡住普卡的毒杀。
- **提醒**：疯子对刚接触《黯月初升》的说书人可能有点难把握，慢慢来就好。

### 配置 4：旅店老板、茶艺师、和平主义者、教授、弄臣、修补匠、魔鬼代言人、沙巴洛斯

- 双方都在想尽办法干掉对方，又都有很多保命手段。善良方要分辨死里逃生是因为和平主义者、魔鬼代言人还是别的原因。
- 沙巴洛斯要聪明地挑"受害者"，因为目标可能受保护，导致当晚无人死亡。
- 死人可能复活（教授 / 沙巴洛斯反刍），善良方要尽力判断是什么触发了复活。

### 配置 5：水手、侍女、吟游诗人、侍臣、赌徒、莽夫、主谋、珀

- 对善良方是个难题：珀能一夜多杀；主谋的威胁让善良方必须想清楚在场的是哪个恶魔、它是死是活，这是获胜关键。
- 善良方可以依赖强大的侍臣，但要用吟游诗人、侍女、赌徒的信息来判断夜里该瞄准哪名玩家或哪个角色。
- 水手和莽夫玩得好的话，也能迷惑邪恶方，给善良方争取时间。

## 四、角色详解

### 镇民

### 祖母（Grandmother）
- **能力**：在你的首个夜晚，你会得知一名善良玩家和他的角色。如果恶魔杀死了他，你也会死亡。
- **要点**：
  - 首夜得知"孙子"：一名善良玩家和他的角色（镇民或外来者）。孙子不知道自己有祖母。
  - 只有**恶魔**杀死孙子时祖母才一起死。处决、赌徒、刺客、教父、造谣者、月之子等其他原因导致孙子死亡，祖母都不死。
- **怎么运作**：首夜准备时把"孙子"标记放在任意一个善良角色旁。首夜唤醒祖母，展示孙子的角色标记，指向孙子玩家，让她入睡。之后如果恶魔杀死了孙子，在夜晚顺序的祖母那一步给祖母放"死亡"标记。白天没有动作。
- **提示标记**：
  - 孙子：放置时机：为首夜做准备时｜放置条件：放在一个善良角色（或能被当作善良的角色）旁｜移除时机：祖母死亡或离场后。
  - 死亡：放置时机：恶魔杀死"孙子"时｜放置条件：恶魔杀死孙子，且祖母此时未醉酒中毒，放在祖母旁，提醒黎明宣布｜移除时机：黎明宣布死亡后随时可移除。
- **规则细节**：
  - 清醒时，祖母得知的应该是善良角色。给邪恶角色会泄露能力之外的信息（暗示有处于善良阵营的邪恶角色，或在不该出现的情况下明示她醉酒中毒）。
  - 普卡、僵怖、沙巴洛斯、珀都是恶魔，它们直接造成的孙子死亡都会带走祖母。普卡的"毒发死亡"也算恶魔杀死（推断：毒杀来自普卡的恶魔能力）。
  - 被教授复活的祖母会立即被唤醒，重新得知一名善良玩家和他的角色（原文范例）。
  - 相克规则：官方相克只涉及其他剧本，已略。
- **范例要点**：
  - 孙子是赌徒，赌错而死 → 祖母存活。
  - 孙子被恶魔杀死，但祖母因水手醉酒 → 祖母存活。
- **说书人注意**：
  - 孙子由说书人挑。挑一个和局势相关的善良玩家，信息才有价值。
  - 祖母首夜醉酒中毒时可以给错的孙子或错的角色，这时甚至可以指向邪恶玩家。
  - 孙子死的那晚祖母如果受旅店老板或茶艺师保护，应当不会死（推断：那两种保护对所有能力造成的死亡都生效）。

### 水手（Sailor）
- **能力**：每个夜晚，你要选择一名存活的玩家：你或他之一会醉酒直到下个黄昏。你不会死亡。
- **要点**：
  - 每晚（含首夜）选一名存活玩家，由说书人决定水手自己醉酒还是对方醉酒。
  - 选了自己，就是自己醉酒，失去"不会死亡"，直到恢复清醒。
  - 选到死亡玩家时，提醒他重新选。
  - 清醒的水手不会以任何方式死亡（夜里被杀、被处决、被造谣者/教父/月之子选中都不死），即使他当晚还没被唤醒。刺客例外。
- **怎么运作**：每晚唤醒水手，让他指一名存活玩家，然后让他入睡。说书人决定醉酒的是水手还是那名玩家，放"醉酒"标记。清醒的水手将要死亡时，他依然存活。被处决时宣布"被处决但依然存活"。
- **提示标记**：
  - 醉酒：放置时机：水手夜晚行动选人后｜放置条件：说书人决定放在水手或被选玩家旁；不能选已死亡玩家；水手此时醉酒中毒则不放｜移除时机：黄昏，或水手死亡或离场时。
- **规则细节**：
  - 惯例：水手选了镇民，通常让那个镇民醉酒；选了外来者、爪牙或恶魔，通常让水手自己醉酒。
  - 水手醉酒中毒（不论原因）就会失去免死。
  - 相克规则：官方相克只涉及其他剧本，已略。
- **范例要点**：
  - 水手让驱魔人醉酒，当晚被沙巴洛斯攻击 → 存活；第二天被处决 → 依然存活。
  - 造谣者的声明为真，当晚水手让自己醉酒 → 说书人可以选水手作为造谣者造成的死者。
  - 水手选了主谋，说书人让水手醉酒；第二天水手要求处决自己"自证" → 死亡。
- **说书人注意**：
  - "谁醉酒"是说书人的重要选择。目标非镇民时让水手自己醉酒，能让他为免死付出代价。
  - 水手选中莽夫（当晚首个选莽夫的人）时，水手自己因莽夫醉酒，莽夫转为水手的阵营。
  - 水手造成的醉酒，在水手死亡或自己醉酒中毒时立即结束（通用规则）。

### 侍女（Chambermaid）
- **能力**：每个夜晚，你要选择除你以外的两名存活的玩家：你会得知他们中有几人在当晚因其自身能力而被唤醒。
- **要点**：
  - 每晚（含首夜）选两名存活玩家，不能选自己，得知 0/1/2，不知道是谁。
  - 只算"为了使用自己的能力而被唤醒"。不算：爪牙信息、恶魔首夜信息、因别人的能力被唤醒（例如恶魔被驱魔人选中后被唤醒得知驱魔人）、不小心被唤醒。
  - 以前的夜晚被唤醒、今晚没有，不算。
  - 醉酒中毒的玩家今晚因自身能力被唤醒，照样算。
  - 被唤醒但选择不使用能力（摇头），也算（原文范例：刺客被唤醒但没出刀，计 1）。
- **怎么运作**：每晚唤醒侍女，让她指除自己外的两名存活玩家，用手势比 0、1 或 2，让她入睡。选到死人或自己时摇头，让她重选。没有两名可选的存活玩家时（例如主谋或僵怖造成的局面）不唤醒侍女。
- **提示标记**：无。
- **规则细节**：
  - 侍女在两种夜晚顺序里都排在最后，计数覆盖当晚所有更早的唤醒。
  - 不需要唤醒的能力不算，例如造谣者的能力、吟游诗人、和平主义者、茶艺师、弄臣、月之子。
  - 没被唤醒的情况不算：首夜的刺客/赌徒/驱魔人等（首夜不行动）；今天白天有人死亡时的僵怖；因"城镇广场上没有死人"而不被唤醒的教授；被驱魔人选中的恶魔（只因驱魔人被唤醒）。
  - 相克规则：官方相克只涉及其他剧本，已略。
- **范例要点**：
  - 驱魔人选中沙巴洛斯；侍女查沙巴洛斯和弄臣 → 0（沙巴洛斯只是因驱魔人被唤醒）。
  - 首夜查刺客和月之子 → 0（刺客首夜不行动）。次夜查刺客（被唤醒但没出刀）和造谣者（发动能力但不用唤醒）→ 1。
- **说书人注意**：
  - 侍女是当晚首个用能力选中莽夫的人时，她自己因莽夫醉酒，可以给假数字。
  - 疯子每晚像恶魔一样被唤醒。原文没写侍女是否把疯子计入；按"因自身能力被唤醒"理解应计入（推断）。
  - 醉酒中毒时给的假数字要和她选中的人的说法、假世界保持一致。

### 驱魔人（Exorcist）
- **能力**：每个夜晚*，你要选择一名玩家（与上个夜晚不同）：如果你选中了恶魔，他会得知你是驱魔人，但他当晚不会因其自身能力而被唤醒。
- **要点**：
  - 首夜以外每晚选一名玩家（可以是死人或自己），不能和上一夜相同。
  - 选中恶魔时：恶魔得知谁是驱魔人，当晚不因自身能力被唤醒，所以不能选人攻击。
  - 恶魔的其他能力照常生效：僵怖被杀仍存活、普卡上一夜毒的人照样死、沙巴洛斯照样可以反刍。
  - 选的不是恶魔：恶魔照常攻击。
- **怎么运作**：首夜以外每晚唤醒驱魔人，让他指一名玩家（指了上一夜的人就摇头，让他换人），给那名玩家放"被选择"标记，让他入睡。如果选中恶魔：唤醒恶魔，展示"该角色的能力对你生效"信息标记和驱魔人角色标记，指向驱魔人，让恶魔入睡。当晚之后不再因恶魔自身能力唤醒他；如果有别的角色能力需要，照样可以唤醒恶魔。
- **提示标记**：
  - 被选择：放置时机：驱魔人夜晚行动选人后｜放置条件：放在被选玩家旁；不能选已有"被选择"的玩家；**不论驱魔人是否醉酒中毒都要放**｜移除时机：驱魔人选了下一个目标后，或驱魔人死亡或离场时。
- **规则细节**：
  - 被驱魔人挡住的珀，这一晚**不算**"没有选择任何人"。但如果珀在被挡的前一晚就没选人，下一次被唤醒时照样能选三人。
  - 驱魔人醉酒中毒时选中恶魔：没有效果，恶魔照常行动，也不会得知驱魔人（推断：能力失效）。
  - 驱魔人选中疯子：疯子不是恶魔，没有效果（推断）。
  - 相克规则：官方相克只涉及其他剧本，已略。
- **范例要点**：
  - 选中沙巴洛斯 → 当晚沙巴洛斯不杀人；如果没有其他死因，黎明无人死亡。
  - 选中普卡 → 普卡不下新毒，但上一夜的中毒者照样死亡。
  - 珀某晚不攻击 → 次晚被驱魔人挡 → 再下一晚驱魔人选了刺客，珀可以选三人（他上一次做选择时没选任何人）。
- **说书人注意**：
  - "上一夜选过的人"只看上一个夜晚，标记跟着最新目标走。
  - 被挡的恶魔被唤醒只是因为驱魔人的能力，侍女不计入。
  - 僵怖当晚本来就不会醒（白天有人死）时被驱魔人选中，按原文仍要唤醒僵怖告知驱魔人身份（夜晚顺序没有附加条件）。

### 旅店老板（Innkeeper）
- **能力**：每个夜晚*，你要选择两名玩家：他们当晚不会死亡，但其中一人会醉酒到下个黄昏。
- **要点**：
  - 首夜以外每晚选两名玩家（可以选自己）。两人当晚不会被恶魔、外来者、爪牙、镇民、旅行者的能力杀死。刺客除外。
  - 只保护夜晚，不保护白天（包括第二天的处决）。
  - 两人中由说书人选一人醉酒，持续当晚和第二天，到下个黄昏为止。通常让善良玩家醉酒，但可以是邪恶玩家。
  - 旅店老板选了自己，并且自己被选为醉酒者，就失去能力：当晚可以死，另一人也不再受保护。
- **怎么运作**：首夜以外每晚唤醒旅店老板，让他指两名玩家，让他入睡。给两人各放"不会死亡"，再给其中一人放"醉酒"。黎明移除"不会死亡"，黄昏移除"醉酒"。
- **提示标记**：
  - 不会死亡（×2）：放置时机：旅店老板夜晚行动选人后｜放置条件：两名被选玩家各放一个；旅店老板此时醉酒中毒则不放｜移除时机：黎明，或旅店老板死亡或离场时。
  - 醉酒：放置时机：成功放置"不会死亡"之后｜放置条件：说书人在两人中选一人放置（旅店老板醉酒中毒、没有放"不会死亡"时也不放）｜移除时机：黄昏，或旅店老板死亡或离场时。
- **规则细节**：
  - 旅店老板当晚稍后死亡或变得醉酒中毒时，保护立即失效（他造成的醉酒也结束）。
  - 普卡：旅店老板保护了"上一个中毒者"，那人当晚不死，并直接恢复健康（普卡的中毒标记被移除）。
  - 相克规则：官方相克只涉及其他剧本，已略。
- **范例要点**：
  - 保护弄臣和侍女，说书人让弄臣醉酒 → 第二天弄臣被处决会直接死亡（醉酒时没有能力）。
  - 保护刺客和珀，让刺客醉酒 → 当晚刺客出刀无效（能力仍被用掉）。
  - 保护自己和和平主义者，让自己醉酒 → 恶魔攻击和平主义者，和平主义者死亡。
  - 修补匠被恶魔攻击，受旅店老板保护没死；当晚稍后旅店老板死亡 → 说书人可以让修补匠也死。
- **说书人注意**：
  - 醉酒的人选是说书人的工具：通常挑当晚或第二天需要准确信息、或要用能力的善良玩家。
  - 旅店老板选中莽夫（当晚首个）时自己醉酒。原文没细说，推断两人都得不到保护、也没人因他醉酒。

### 赌徒（Gambler）
- **能力**：每个夜晚*，你要选择一名玩家并猜测该玩家的角色：如果你猜错了，你会死亡。
- **要点**：
  - 首夜以外每晚选一名玩家（死活皆可，也可以选自己），并在角色列表上指一个角色。
  - 猜对无事发生，猜错赌徒死亡。赌徒不会被告知对错。
- **怎么运作**：首夜以外每晚唤醒赌徒，让他指一名玩家，再指角色列表上的一个图标，让他入睡。猜错（该玩家的真实角色和图标不同）就给赌徒放"死亡"标记。
- **提示标记**：
  - 死亡：放置时机：赌徒夜晚行动后｜放置条件：猜错且赌徒可以死亡时放在赌徒旁；赌徒醉酒中毒时无论对错都不放｜移除时机：黎明宣布后随时可移除。
- **规则细节**：
  - "可以死亡"：赌徒受旅店老板/茶艺师保护、是清醒的水手等情况下不会因此而死（推断，标记条件写的是"赌徒可以死亡"）。
  - 判定看真实角色：疯子的真实角色是"疯子"，猜他是某种恶魔算错。
  - 相克规则：无。
- **范例要点**：
  - 猜吟游诗人猜对，仍可能当晚被恶魔杀死。
  - 魔鬼代言人伪装和平主义者，赌徒猜"和平主义者" → 猜错，赌徒死亡。
- **说书人注意**：
  - 赌徒选中莽夫（当晚首个）时自己醉酒：猜错也不死，莽夫转为赌徒的阵营。
  - 赌徒的死在黎明和其他夜晚死亡一起公布，不说原因。

### 造谣者（Gossip）
- **能力**：每个白天，你可以公开发表一个声明。如果该声明正确，在当晚会有一名玩家死亡。
- **要点**：
  - 每个白天可以公开发表一个声明。为真，说书人当晚杀死一名玩家；为假，没人因此而死。
  - 含糊、低声、说书人无法判断真假、有人没听到的声明都不作数。说书人和所有玩家都必须听清，并明白造谣者在使用能力。
  - 白天醉酒中毒时说了真话，只要当晚轮到造谣者时他清醒健康，仍然死一人（回溯型能力）。
- **怎么运作**：白天造谣者做出清晰且为真的公开声明时，把造谣者的"死亡"标记放在魔典中央。首夜以外的夜晚，轮到造谣者时，说书人选任意一名玩家死亡，把标记移到那名玩家旁。
- **提示标记**：
  - 死亡：放置时机：造谣者发表公开声明后｜放置条件：声明清晰且为真就放在魔典中央，不论造谣者当时是否醉酒中毒｜移动：轮到造谣者夜晚行动时，移到说书人选定的玩家旁（应倾向选能死的人）；如果此时造谣者醉酒中毒，或已死亡、离场，直接移除｜移除时机：黎明宣布后，或造谣者死亡或离场时。
- **规则细节**：
  - 造谣者当晚在轮到他之前死了（例如被恶魔杀死）→ 失去能力，没人因他的声明而死。
  - 造谣者造成的死亡可以被各种免死能力挡住（茶艺师、旅店老板、清醒的水手、弄臣等）。
  - 相克规则：无。
- **范例要点**：
  - "恶魔戴着帽子"，恶魔没戴 → 无人因此死亡。
  - 醉酒时说"我两个邻座都是善良的"（为真），黄昏恢复清醒 → 当晚有人死亡（死者是侍女，由说书人选）。
  - 声明为真，但当晚造谣者被恶魔杀死 → 无人因声明而死。
- **说书人注意**：
  - 推荐选能死的玩家，不要选受保护的（弄臣、茶艺师邻座等）。让声明真的造成死亡，造谣者才能拿到信息。
  - 声明真假按当前的真实游戏状态判断（不考虑醉酒中毒造成的错觉）。拿不准就判不作数，并且要当场判断清楚。
  - 水手让自己醉酒时，水手也可以被选为死者。

### 侍臣（Courtier）
- **能力**：每局游戏限一次，在夜晚时，你可以选择一个角色：如果该角色在场，该角色之一从当晚开始醉酒三天三夜。
- **要点**：
  - 每局一次，任何夜晚（含首夜）都能用。选的是**角色**（指角色列表），不是玩家。要提醒侍臣，以及伪装侍臣的邪恶玩家。
  - 立即生效，持续 3 个夜晚 + 3 个白天。侍臣不会得知成败，可能选到不在场的角色。
  - 侍臣醉酒中毒时使用：无效，能力用掉，之后恢复也不会补。
  - 生效后侍臣变得醉酒中毒（或死亡）：目标立即恢复清醒。侍臣在三天三夜结束前恢复清醒健康：目标继续醉酒，直到原定结束。
- **怎么运作**：每晚唤醒侍臣，他摇头（不用）或指一个角色图标，让他入睡。用了能力且该角色在场，给对应玩家放"醉酒1"。下一个黄昏换成"醉酒2"，再下一个黄昏换成"醉酒3"，再下一个黄昏移除，给侍臣放"失去能力"。侍臣用过能力后，本局不再唤醒他。
- **提示标记**：
  - 醉酒1：放置时机：侍臣夜晚选择使用能力并选了一个角色后｜放置条件：侍臣未醉酒中毒，且所选角色在场；同角色多个时由说书人选一个｜移除时机：黄昏时换成"醉酒2"（不论侍臣此时是否醉酒中毒）；侍臣死亡或离场则直接移除。
  - 醉酒2：放置时机：只由"醉酒1"在下一个黄昏替换而来｜放置条件：目标不变｜移除时机：再下一个黄昏换成"醉酒3"（不论侍臣是否醉酒中毒）；侍臣死亡或离场则移除。
  - 醉酒3：放置时机：只由"醉酒2"在下一个黄昏替换而来｜放置条件：目标不变｜移除时机：再下一个黄昏移除，并给侍臣放"失去能力"（不论侍臣是否醉酒中毒）；侍臣死亡或离场也移除。
  - 失去能力：放置时机："醉酒3"到期的那个黄昏，或侍臣在醉酒中毒期间使用能力时｜放置条件：满足以上任一时机，放在侍臣旁｜移除时机：侍臣死亡或离场时。
- **规则细节**：
  - 选了不在场的角色：没有效果，能力同样用掉、不再唤醒（原文没单独写"失去能力"标记，按"用过即不再唤醒"处理）。
  - 侍臣醉酒中毒期间，"醉酒N"标记照样按黄昏推进，只是目标暂时清醒。
  - 选"莽夫"也算侍臣用能力选中了莽夫：侍臣若是当晚首个选中莽夫的人，侍臣自己醉酒，能力浪费，莽夫转为侍臣的阵营（原文范例）。
  - 疯子以为的恶魔和真恶魔不同时，侍臣选"疯子以为的那个恶魔"不会命中任何人（推断：该角色不在场）。选"疯子"会让疯子玩家醉酒。
  - 相克规则：官方相克只涉及其他剧本，已略。
- **范例要点**：
  - 第五夜才用，灌醉沙巴洛斯 → 从当晚起三个夜晚，沙巴洛斯照常行动但杀不死人。
  - 醉酒时用能力 → 无事发生，之后再也不唤醒。
  - 灌醉主谋，之后珀被处决 → 主谋能力失效，游戏结束，善良获胜。
- **说书人注意**：
  - 三天三夜的计数：使用当晚 = 第 1 夜，之后经过三个黄昏才结束（第 1、2、3 夜和随后的三个白天）。
  - 被灌醉的是恶魔时，恶魔照常唤醒、照常选人，只是没有效果；要把这种情况当作"恶魔中毒"来处理（普卡见普卡一节）。

### 教授（Professor）
- **能力**：每局游戏限一次，在夜晚时*，你可以选择一名死亡的玩家：如果他是镇民，你会将他起死回生。
- **要点**：
  - 每局一次，首夜以外。选一名死亡玩家：是镇民就复活。
  - 选了外来者、爪牙、恶魔：无事发生，能力用掉。
  - 被复活的玩家重新获得能力，包括已经用过的"每局限一次"能力。
  - 被复活者当晚能不能行动，看他的夜晚顺序在教授之前还是之后。"在你的首个夜晚"的能力在教授入睡后立即唤醒使用。
- **怎么运作**：首夜以外每晚唤醒教授，他摇头或指一名死亡玩家，让他入睡。选中死亡的镇民：给那人放"复活"标记，移除帷幕标记，他再次存活。顺序在教授之后的角色当晚照常唤醒；只在首夜行动的角色（祖母）立即唤醒。黎明先宣布死亡，再宣布谁复活了（不说原因）。教授放"失去能力"，从夜晚顺序移除。
- **提示标记**：
  - 复活：放置时机：教授夜晚选择使用能力并选了一名死亡玩家后｜放置条件：被选玩家此时是镇民，且教授未醉酒中毒｜移除时机：黎明宣布复活后随时可移除。
  - 失去能力：放置时机：同上｜放置条件：只要选了死亡玩家，不论教授是否醉酒中毒都放｜移除时机：教授死亡或离场时。
- **规则细节**：
  - 城镇广场上没有死亡玩家时不唤醒教授（即使已经有人死了但还没公布），侍女也不会因此探测到教授醒来。
  - 必须选死亡玩家。指了存活玩家（例如当晚刚被沙巴洛斯反刍的人）就摇头，让他重选。
  - 在教授之后行动、复活后当晚就能行动的角色：造谣者（声明结算）、祖母（立即）、侍女。复活后当晚不能行动的：水手、旅店老板、侍臣、赌徒、驱魔人。
  - 相克规则：官方相克只涉及其他剧本，已略。
- **范例要点**：
  - 选了自称茶艺师的死人，实际是疯子 → 无人复活，能力用掉。
  - 复活祖母 → 祖母立即得知一名善良玩家的角色；黎明大家只知道这名玩家复活了，不知道他是祖母。
  - 醉酒的教授先指了刚被反刍的（存活的）吟游诗人 → 摇头 → 改指死亡的弄臣 → 因醉酒无事发生，能力用掉。
- **说书人注意**：
  - 被复活者的"死于今日"、帷幕等状态全部撤销，按存活玩家对待（重新算茶艺师邻座等）。
  - 僵怖被当作死亡时，被教授选中也不会复活（不是镇民）。

### 吟游诗人（Minstrel）
- **能力**：当一名爪牙死于处决时，除了你和旅行者以外的所有其他玩家醉酒直到明天黄昏。
- **要点**：
  - 爪牙玩家被处决**并且死亡**的那一刻，除吟游诗人和旅行者外的所有玩家（包括恶魔）立即醉酒，持续整个夜晚和下一个白天，到下一个黄昏。
  - 爪牙在夜里死亡不触发。
  - 不触发：处决已经死亡的爪牙（死人不会再死）、爪牙被处决但没死、处决时吟游诗人醉酒中毒。
- **怎么运作**：白天爪牙死于处决时，把"全员醉酒"标记放在魔典中央。第二天黄昏，所有因吟游诗人醉酒的玩家恢复清醒，移除标记。白天、夜里吟游诗人都不需要唤醒。
- **提示标记**：
  - 全员醉酒：放置时机：有爪牙死于处决时｜放置条件：吟游诗人此时未醉酒中毒，放在魔典中央（建议：每到黎明把标记从中央移到吟游诗人旁；黄昏时如果标记在吟游诗人旁就移除，在中央就保留）｜移除时机：放置后的下一个黄昏；如果当天又有爪牙死于处决就重新放置；吟游诗人死亡或离场时也移除。
- **规则细节**：
  - "爪牙"指角色类型。邪恶的莽夫、疯子是外来者，被处决不触发。
  - 全员醉酒的夜里，恶魔、刺客、教父的击杀都无效，侍女等拿到的信息可以是假的，修补匠不会因自身能力而死，和平主义者、魔鬼代言人当天保不了人，普卡上一个中毒者当晚不死。
  - 相克规则：官方相克只涉及其他剧本，已略。
- **范例要点**：
  - 教父被处决 → 当晚所有人醉酒，包括恶魔，无人死亡。
  - 魔鬼代言人醉酒时，他保护的爪牙被处决并死亡 → 再次全员醉酒。
  - 刺客死于处决 → 全员醉酒；第二天僵怖第一次被处决 → 僵怖醉酒没有能力，真的死亡，善良获胜。
- **说书人注意**：
  - 连续两天都处决爪牙时，效果顺延，第二天的黄昏不移除。
  - 吟游诗人本人不醉酒，所以他死亡或醉酒时效果立即结束（通用规则：效果来源失去能力，持续效果终止）。

### 茶艺师（Tea Lady）
- **能力**：如果与你邻近的两名存活的玩家是善良的，他们不会死亡。
- **要点**：
  - 茶艺师两侧最近的两名存活玩家**当前都是善良**时，这两人都不会死亡：恶魔、教父、造谣者杀不死，被处决也不死。唯一例外是刺客。
  - 邻座跳过死人：顺时针最近的存活玩家 + 逆时针最近的存活玩家。
  - 只要有一个邻座是邪恶的，保护就不生效。邪恶邻座死后，新的两个邻座都善良时，保护重新生效。
  - 茶艺师不保护她自己。
- **怎么运作**：持续检测。两个存活邻座都善良时，给两人放"不会死亡"；任一个是邪恶时移除。阵营变化、死亡、复活时都要重新检查。被保护者将要死亡时依然存活；被处决时宣布"被处决但依然存活"。
- **提示标记**：
  - 不会死亡（×2）：放置时机：茶艺师的两名存活邻座都属于善良阵营时｜放置条件：动态检测，满足就放，不满足立即移除，放在两名存活邻座旁｜移除时机：茶艺师死亡或离场时，或检测条件不再满足时。
- **规则细节**：
  - 茶艺师醉酒中毒时保护失效；恢复后保护恢复（通用规则）。
  - 被当作死亡的僵怖不算存活邻座，会被跳过。
  - 死亡是依次发生的：保护在某一次死亡结算时是否有效，看那一刻的状态。
  - 相克规则：无。
- **范例要点**：
  - 开局邻座是主谋和善良的莽夫 → 主谋被处决死亡后，邻座变成莽夫和侍臣（都善良）→ 恶魔攻击侍臣，侍臣存活；后来莽夫变邪恶，恶魔再攻击侍臣 → 侍臣死亡。
  - 沙巴洛斯先攻击茶艺师的邻座（受保护不死），再攻击茶艺师（死亡）→ 邻座仍存活。
  - 邻座是善良的莽夫和修补匠 → 修补匠被处决不死；第二天莽夫变邪恶 → 再处决修补匠就死亡。
- **说书人注意**：
  - 修补匠在受茶艺师保护时不能因自身能力死亡。
  - 程序要在每次死亡、复活、阵营变化（莽夫）、醉酒状态变化后重新计算保护。

### 和平主义者（Pacifist）
- **能力**：被处决的善良玩家可能不会死亡。
- **要点**：
  - 善良玩家被处决时，由说书人决定他死还是活。
  - 只告诉大家处决成功但没死，不说原因。
  - 被处决但存活仍然算今天的处决，当天不能再提名。
- **怎么运作**：善良角色被处决时，宣布死亡或"被处决但依然存活"（不说原因），然后进入夜晚。每天最多一次处决。
- **提示标记**：无。
- **规则细节**：
  - 只管处决，不管流放的旅行者，也不管夜晚死亡。
  - 看的是**阵营**：善良的外来者（如疯子）也能被救，邪恶的莽夫不能。
  - 和平主义者醉酒中毒或已死亡时不能救人。他自己被处决也可以被救。
  - 相克规则：无。
- **范例要点**：
  - 疯子被处决依然存活；第二天和平主义者醉酒，教授被处决死亡；第三天主教被流放死亡（流放不算处决）；第四天和平主义者自己被处决，依然存活。
  - 善良方占优时，可以七天里五次处决善良玩家都不救。
- **说书人注意**：
  - 每局触发一次通常合理，觉得合适可以多次。少数情况下为了让和平主义者显得可疑，可以永不触发。
  - 这是平衡工具：局势倾向邪恶时更应该触发。

### 弄臣（Fool）
- **能力**：当你首次将要死亡时，你不会死亡。
- **要点**：
  - 第一次因任何原因将要死亡时依然存活，弄臣不知道是自己的能力救了自己。
  - 如果别的能力已经让他免死（茶艺师、旅店老板等），弄臣的能力不会被用掉。只有真正将要死去时才触发。
- **怎么运作**：弄臣将要死亡时依然存活（醉酒中毒时则会死）。被处决时宣布"被处决但依然存活"。两种情况下都放"失去能力"。白天、夜里都不唤醒。
- **提示标记**：
  - 失去能力：放置时机：弄臣的能力触发时｜放置条件：弄臣没有受其他免死效果保护、自己未醉酒中毒、即将死亡、且还没有"失去能力"时，放在弄臣旁｜移除时机：弄臣死亡或离场时。
- **规则细节**：
  - 刺客无视弄臣的能力，弄臣直接死亡并保持死亡。
  - 被普卡毒的弄臣没有能力：第二天被处决会死，或在下一夜毒发而死。
  - 被复活（教授）或反刍（沙巴洛斯）的弄臣重新获得能力（通用：复活者重获能力）。
  - 相克规则：无。
- **范例要点**：
  - 第一天被处决存活；第四天再被处决 → 死亡。
  - 恶魔攻击弄臣，被茶艺师保护 → 存活且保留能力；茶艺师死后被旅店老板保护 → 仍保留能力；旅店老板死后再被攻击 → 存活但用掉能力，下次死亡。
- **说书人注意**：
  - 判定顺序：先看其他免死保护，再看弄臣自己的能力。
  - 造谣者、月之子、教父的击杀落到弄臣头上，也会用掉他的能力；造谣者的死者由说书人选时，推荐别选弄臣。

### 外来者

### 修补匠（Tinker）
- **能力**：你随时可能死亡。
- **要点**：
  - 说书人随时可以杀死修补匠，不需要理由。
  - 修补匠受免死能力保护时不能因自身能力死亡。
- **怎么运作**：任何时候都可以决定让他死。白天：立即宣布修补匠刚刚死亡（直接放帷幕）。夜晚：放"死亡"标记，黎明一起宣布。都不说原因。夜晚顺序里修补匠那一步（造谣者之后）是提醒，但"随时"都可以。
- **提示标记**：
  - 死亡：放置时机：夜晚期间说书人决定修补匠死亡时｜放置条件：放在修补匠旁，提醒黎明宣布；白天死亡不放此标记，直接放帷幕并让玩家翻生命标记｜移除时机：黎明宣布后随时可移除。
- **规则细节**：
  - 修补匠醉酒中毒时不会因自身能力死亡（原文吟游诗人一节：全员醉酒时修补匠不会在那天随机死亡）。
  - 修补匠白天死亡算"外来者在白天死亡"，会触发教父；也算"今天白天有人死亡"，僵怖当晚不醒。
  - 相克规则：无。
- **范例要点**：
  - 第三个白天突然死亡。
  - 受茶艺师保护时不会因自身能力死亡。
  - 被恶魔攻击时受旅店老板保护没死，当晚稍后旅店老板死亡 → 说书人可以让修补匠死。
  - 魔鬼代言人保护的修补匠被处决：处决不致死，但说书人仍可以用修补匠的能力让他死（宣布"被处决，然后死亡"，不说原因）。
- **说书人注意**：
  - 死在夜里比白天更有意思：玩家会猜他是自己死的还是被杀的。
  - 可以一直不杀他（他会显得可疑）。
  - 如果杀死修补匠会让游戏结束（例如只剩 3 人），**永远不要**这样做。胜负应当由玩家决定。

### 月之子（Moonchild）
- **能力**：当你得知你死亡时，你要公开选择一名存活的玩家。如果他是善良的，在当晚他会死亡。
- **要点**：
  - 得知自己死亡后（被处决后，或黎明公布死讯后）一到两分钟内，必须公开选一名存活玩家，可以先听听大家意见。
  - 选中善良玩家 → 当晚该玩家死亡；选中邪恶玩家 → 无事发生。
  - 说书人没有义务提醒；故意不用算作弊。邪恶玩家伪装月之子"选人"时，说书人要配合（无事发生）。
  - 醉酒中毒按夜里结算时判断：夜里清醒健康而白天选人时醉酒中毒 → 所选玩家会死；夜里醉酒中毒而白天选人时清醒 → 所选玩家不会死。
  - 选中时莽夫是善良的 → 莽夫会死，不管他夜里阵营怎么变。
- **怎么运作**：宣布月之子死亡时，月之子公开选一名存活玩家。如果那人是善良的，给他放月之子的"死亡"标记。当晚轮到月之子时，该玩家死亡（月之子此时须清醒健康）。新手没意识到要选人时，可以私下提醒。
- **提示标记**：
  - 死亡：放置时机：月之子得知自己死亡、用能力选了一名存活玩家时｜放置条件：所选玩家属于善良阵营就放，不论月之子选人时是否醉酒中毒（回溯型能力）｜移除时机：黎明宣布后随时可移除；或轮到月之子夜晚行动时月之子醉酒中毒、或月之子离场，则移除。
- **规则细节**：
  - 死亡发生在夜里，所以目标受旅店老板、茶艺师保护，或是清醒的水手、弄臣时，不会死（原文玩家技巧中提及）。
  - 月之子被处决但没死（和平主义者等）→ 他没有得知自己死亡，不能选人。
  - 月之子白天死亡，同时也会触发教父。
  - 相克规则：官方相克只涉及其他剧本，已略。
- **范例要点**：
  - 普卡杀死月之子 → 第二天选中驱魔人 → 当晚驱魔人死亡。
  - 月之子被处决、选了侍臣，当晚普卡选中（已死亡的）月之子 → 月之子中毒，侍臣不死。
  - 被沙巴洛斯吞食，选刺客无效；之后被反刍，再次被吞食 → 选造谣者，造谣者死亡（每次死亡都能再触发）。
- **说书人注意**：
  - 判定阵营看选人那一刻；判定能力是否有效看夜里结算那一刻。
  - 和教父连用时，同一天可能出现两次额外死亡。

### 莽夫（Goon）
- **能力**：每个夜晚，首个使用其自身能力选择了你的玩家会醉酒直到下个黄昏。你会转变为他的阵营。
- **要点**：
  - 每个夜晚，第一个用自己的能力选中莽夫的玩家立即醉酒，他的能力当晚和第二天都不生效（到下个黄昏）。
  - 同一晚之后再有人用能力选中莽夫，正常生效。
  - 只有玩家自己选中莽夫才算。说书人替能力选人（例如祖母的孙子）不算。
  - 一旦让人醉酒，莽夫转为那名玩家的阵营。选他的人本来就醉酒中毒，照样醉酒并且照样转阵营。
  - 被刺客选中：莽夫死亡，但仍转为邪恶。
- **怎么运作**：夜里，有玩家用自身能力选中莽夫、且莽夫的"醉酒"标记还没放出时，给那名玩家放"醉酒"，结算他的能力（已醉酒、无效），让他入睡。如果他和莽夫阵营不同，把莽夫的角色标记转向（正放善良、倒放邪恶），唤醒莽夫，用拇指手势告诉他新阵营，让他入睡。下个黄昏移除"醉酒"。
- **提示标记**：
  - 醉酒：放置时机：每个夜晚莽夫第一次被其他玩家用自身能力选中时（不论该能力会不会产生效果，不论选他的人当时是否醉酒中毒）｜放置条件：放在那名玩家旁（判断"是否首次"只看莽夫的醉酒标记有没有已经放在魔典里）｜移除时机：黄昏，或莽夫死亡或离场时。
- **规则细节**：
  - 醉酒立即生效，**连这次选择本身也会失效**。多目标能力按选择顺序结算，选到莽夫那一刻起，后面的目标都受醉酒影响。
  - 角色和阵营互相独立：莽夫变邪恶后仍是莽夫（外来者），被处决不触发吟游诗人。
  - 莽夫死亡后失去能力，阵营锁定。
  - 普卡选中莽夫：普卡当场醉酒，莽夫不中毒；并且普卡结算"上一个中毒者死亡"时已经醉酒，这一步跳过（推断：依普卡标记规则和莽夫原文"普卡在毒死你之前就出了问题"）。
  - 相克规则：官方相克只涉及其他剧本，已略。
- **范例要点**：
  - 侍臣选"莽夫" → 莽夫转善良，侍臣醉酒（能力浪费）。
  - 沙巴洛斯先选莽夫再选造谣者 → 两人都不死，莽夫转邪恶；下一夜先选赌徒再选莽夫 → 赌徒死亡，沙巴洛斯再次醉酒，莽夫存活仍为邪恶。
  - 侍女查莽夫和吟游诗人，因莽夫醉酒，得到错误的"1"。
  - 珀依次选月之子、莽夫、祖母 → 只有月之子死亡。
- **说书人注意**：
  - 要严格按当晚的唤醒顺序判断"首个"：水手、旅店老板、侍臣、赌徒、魔鬼代言人、驱魔人、恶魔、刺客、教父……谁先选中谁中招。
  - 莽夫被唤醒告知阵营，是因为阵营变化，不是他发动了能力（侍女计不计入原文未说明）。
  - 茶艺师的邻座是莽夫时，莽夫转阵营会立即改变茶艺师的保护。

### 疯子（Lunatic）
- **能力**：你以为你是一个恶魔，但其实你不是。恶魔知道你是疯子以及你在每个夜晚选择了哪些玩家。
- **要点**：
  - 疯子不知道自己的真实角色和阵营（他是善良的外来者）。每晚像真恶魔一样被唤醒攻击，但选择没有任何效果。
  - 首夜（7 人及以上）得知"爪牙"（人数对，但可以是任何人）和三个善良角色"伪装"，这些信息可以是错的（伪装甚至可以是在场角色）。
  - 真恶魔知道谁是疯子，以及疯子每晚选了谁。
- **怎么运作**：
  - 设置：疯子玩家拿到的是恶魔标记（可以是真恶魔的同种，也可以是另一种恶魔），魔典里记作疯子。
  - 首夜：唤醒疯子，按恶魔流程展示"他们是你的爪牙"并指向若干名玩家（数量等于在场爪牙数），展示三个善良角色作为伪装，让他入睡。唤醒真恶魔：展示"你是"+恶魔角色标记，再展示"这名玩家是"+疯子角色标记，指向疯子。
  - 其他夜晚（在驱魔人和真恶魔之前）：唤醒疯子，按他以为的恶魔行动，给他选的每名玩家放"被选择"，让他入睡。唤醒真恶魔，指向疯子，展示疯子标记，再指向疯子选的玩家。然后真恶魔照常行动。
- **提示标记**：
  - 被选择（共 3 枚）：放置时机：疯子夜晚行动选人后｜放置条件：按疯子以为的那种恶魔，让他选对应数量的玩家，每人旁放一个，用来提醒告诉真恶魔｜移除时机：黎明。
  - 是疯子（仅线上魔典）：用法同酒鬼的"是酒鬼"。
- **规则细节**：
  - 疯子以为自己是僵怖：只在"今天白天没人死亡"的夜里才唤醒他。以为是珀：可以不选，下次选三人。以为是沙巴洛斯：每晚选两人。
  - 疯子死亡不结束游戏；疯子被处决算外来者死于白天（触发教父），不触发吟游诗人。
  - 教授选中疯子：不是镇民，不复活。赌徒必须猜"疯子"才算对。
  - 5–6 人局原文只写了 7 人及以上的首夜流程。能力写明"恶魔知道你是疯子"，所以少于 7 人时仍应告诉真恶魔谁是疯子（推断）。
  - 相克规则：官方相克只涉及其他剧本，已略。
- **范例要点**：
  - 以为自己是沙巴洛斯，每晚选两人 → 都不会死。
  - 以为自己是僵怖 → 不是每晚都醒；真僵怖假装是他的爪牙，并总是攻击疯子选的人，维持假象。
- **说书人注意**：
  - 疯子以为的恶魔是普卡时，首夜也应该让他像普卡一样选人，以维持假象（推断：原文首夜顺序只列了信息步骤）。
  - 给疯子的"爪牙"可以指善良玩家、其他外来者或真爪牙；伪装可以给在场角色，作为他不是恶魔的暗示。
  - 疯子每晚的选择要准确告诉真恶魔，真恶魔被驱魔人挡住的夜晚也一样（疯子这一步在驱魔人之前）。
  - 疯子是善良的：算茶艺师的善良邻座、能被和平主义者救、月之子选他会死。

### 爪牙

### 教父（Godfather）
- **能力**：在你的首个夜晚，你会得知有哪些外来者角色在场。如果有外来者在白天死亡，你会在当晚被唤醒并且你要选择一名玩家：他死亡。[-1或+1外来者]
- **要点**：
  - 设置时外来者 +1 或 -1。
  - 首夜得知在场的外来者角色。
  - 外来者在**白天**死亡（处决或其他原因，如修补匠白天暴毙），当晚教父被唤醒并杀一人。外来者在夜晚死亡不算。
  - 同一天死了两个外来者，当晚也只杀一人。
- **怎么运作**：设置时（放盲抽袋前）把一个镇民换成外来者，或把一个外来者换成镇民。首夜唤醒教父，展示所有在场外来者的角色标记。外来者白天死亡时，给他放"死于今日"；当晚唤醒教父，让他指一名玩家，那人死亡，放"死亡"标记。
- **提示标记**：
  - 死于今日：放置时机：白天有外来者死亡时，不论死因｜放置条件：放在死亡的外来者旁，不论教父此时是否醉酒中毒；一天多名外来者死亡也只放一个｜移除时机：教父夜晚行动后随时可移除。
  - 死亡：放置时机：教父夜晚行动选人后｜放置条件：所选玩家当前存活、能被教父杀死、教父未醉酒中毒｜移除时机：黎明宣布后随时可移除。
- **规则细节**：
  - 原文"角色简介"写"每当外来者死于处决"，但能力和标记说明都是"白天死亡、不论死因"，范例中修补匠白天因自身能力死亡也触发了。按能力文字实现。
  - 外来者被处决但没死（魔鬼代言人、和平主义者、茶艺师等）→ 不触发。处决已经死亡的外来者 → 不算死亡，不触发。
  - 邪恶的莽夫白天死亡同样触发（他仍是外来者）。
  - 回溯型：白天时教父醉酒不影响，只看夜里行动时是否清醒健康。
  - 教父可以选死人来隐藏自己（不会造成死亡）。
  - 相克规则：官方相克只涉及其他剧本，已略。
- **范例要点**：
  - 疯子死于处决 → 当晚恶魔杀吟游诗人，教父杀和平主义者（一夜两死）。
  - 修补匠被处决但因魔鬼代言人存活 → 教父当晚不行动；第二天修补匠因自身能力白天死亡 → 当晚教父行动（他甚至选了自己来伪装好人）。
- **说书人注意**：
  - +1 还是 -1 由说书人在设置时决定，外来者数量本身就是线索。
  - 外来者为 0 时只能 +1；首夜给教父看"没有外来者"时就什么都不展示（推断）。
  - 教父被侍臣灌醉或在吟游诗人效果下，当晚的击杀无效。

### 魔鬼代言人（Devil's Advocate）
- **能力**：每个夜晚，你要选择一名存活的玩家（与上个夜晚不同）：如果明天白天他被处决，他不会死亡。
- **要点**：
  - 每晚（含首夜）选一名存活玩家（可以选自己），第二天该玩家被处决：处决成功但他不死。
  - 不能连续两晚选同一人（不论那人有没有被处决）。不能选被当作死亡的僵怖。
- **怎么运作**：每晚唤醒他，让他指一名玩家；选了上一夜的人或死人就提醒换人。让他入睡，给那名玩家放"处决不死"。第二天该玩家被处决时，宣布"被处决但依然存活"。
- **提示标记**：
  - 处决不死：放置时机：魔鬼代言人行动选人后｜放置条件：放在所选玩家旁；不能选已有此标记的玩家；魔鬼代言人醉酒中毒时也要放，但倒置表示无效，只用来记录"上一夜选过谁"｜移除时机：魔鬼代言人选了下一个目标后，或魔鬼代言人死亡或离场时。
- **规则细节**：
  - 保护只在选择后的**下一个白天**对处决生效，不管夜晚死亡。
  - 处决时魔鬼代言人醉酒中毒（例如吟游诗人效果）→ 保护无效。
  - 只挡"处决导致的死亡"：被保护的修补匠被处决后，说书人仍可以用修补匠的能力让他死。
  - 相克规则：无。
- **范例要点**：
  - 保护自己 → 第二天被处决，依然存活。
  - 保护僵怖 → 僵怖被处决依然存活，生命标记不翻；第二天再被处决 → 被当作死亡（第一次死亡）。
  - 保护月之子，法官强制处决成功 → 处决执行，但月之子依然存活。
- **说书人注意**：
  - 被处决但存活仍算当天的处决，当天不能再提名。
  - 外来者被他保住时不算白天死亡，教父不触发；僵怖当晚会醒（没人死）。

### 刺客（Assassin）
- **能力**：每局游戏限一次，在夜晚时*，你可以选择一名玩家：他死亡，即使因为任何原因让他不会死亡。
- **要点**：
  - 每局一次，首夜以外。选一名玩家：他死亡，任何免死保护都挡不住（旅店老板、茶艺师、清醒的水手、弄臣、莽夫）。
  - 刺客的能力照常受醉酒中毒影响：醉酒中毒时出刀无效，能力仍然用掉。
  - 刺中莽夫：莽夫死亡，并转为邪恶。
  - 刺中尚未触发能力的僵怖：僵怖"死亡"，随即触发能力，仍存活（被当作死亡）。
- **怎么运作**：首夜以外每晚唤醒刺客，他摇头或指一名玩家，让他入睡。选了人：那人死亡，放"死亡"标记（这次死亡任何方式都挡不住，除非刺客没有能力）。刺客放"失去能力"，从夜晚顺序移除，不再唤醒。
- **提示标记**：
  - 死亡：放置时机：刺客夜晚选择使用能力并选了一名玩家后｜放置条件：所选玩家当前存活，且刺客未醉酒中毒｜移除时机：黎明宣布后随时可移除。
  - 失去能力：放置时机：同上｜放置条件：只要选了玩家，不论刺客是否醉酒中毒都放｜移除时机：刺客死亡或离场时。
- **规则细节**：
  - 依据"不能"大于"能"的隐性规则：刺客让"保护某人不会死"的能力无法生效。
  - 刺客杀死孙子不会带走祖母（刺客不是恶魔）。
  - 相克规则：无。
- **范例要点**：
  - 第四夜刺杀弄臣 → 弄臣虽然还有能力，仍然死亡。
  - 刺杀茶艺师保护下的邻座 → 死亡。
  - 吟游诗人在场、主谋被处决，当晚刺客刺月之子 → 不死（刺客因吟游诗人醉酒）。
  - 被侍臣灌醉的刺客刺莽夫 → 刺客能力用掉，莽夫存活但转为邪恶。
- **说书人注意**：
  - 刺客摇头不出刀时仍然算"被唤醒"（侍女计入）。
  - 被刺客杀死的弄臣，能力不算用掉，但人已经死了。

### 主谋（Mastermind）
- **能力**：如果恶魔因为死于处决而因此导致游戏结束时，再额外进行一个夜晚和一个白天。在那个白天如果有玩家被处决，他的阵营落败。
- **要点**：
  - 最后一个存活的恶魔死于处决时游戏继续，玩家不会得知刚死的是恶魔。
  - 额外的白天：处决了善良玩家（不论他死没死）→ 邪恶获胜；处决了邪恶玩家，或没有处决 → 善良获胜。
  - 死亡的恶魔不能攻击，照常失去能力；额外的夜晚和白天里其他角色的能力正常生效。
  - 恶魔死后只剩两名存活玩家时，仍然额外进行一天：邪恶不会因为只剩两人而获胜，善良也不会因杀死恶魔而立即获胜。主谋能力覆盖常规规则。
- **怎么运作**：恶魔死于处决、游戏本该结束时，继续游戏（照常放帷幕，不说恶魔死了）。第二天：处决了善良玩家 → 宣布邪恶获胜；处决了邪恶玩家或没有处决 → 宣布善良获胜。
- **提示标记**：无。
- **规则细节**：
  - 只有"处决"导致恶魔死亡才触发。恶魔在夜里死亡（例如被刺客刺死）不触发。
  - 主谋必须存活、且在恶魔被处决时清醒健康，能力才生效（通用规则）。被侍臣灌醉的主谋不触发，善良立即获胜。
  - 僵怖第一次被处决（被当作死亡）不会结束游戏，不触发；第二次真死时才触发。
  - 额外夜晚里主谋自己死亡会怎样，原文没有说明，由说书人按理念判断。
  - 相克规则：官方相克只涉及其他剧本，已略。
- **范例要点**：
  - 沙巴洛斯被处决死亡 → 第二天教授被处决死亡 → 邪恶获胜。
  - 珀被处决死亡 → 第二天教父被处决，因魔鬼代言人存活 → 处决的是邪恶玩家，善良获胜。
  - 三人存活时恶魔被处决 → 夜里有人死，只剩两人；第二天善良决定不处决 → 善良获胜。
- **说书人注意**：
  - 额外白天的胜负只看"被处决者的阵营"，不看他死没死（和平主义者救下的善良玩家被处决也算邪恶胜）。
  - 主谋在场且恶魔死于处决时，**不要**宣布游戏结束，夜晚照常进行（刺客、教父、赌徒、造谣者、修补匠都可能造成死亡）。

### 恶魔

### 僵怖（Zombuul）
- **能力**：每个夜晚*，如果今天白天没有人死亡，你会被唤醒并要选择一名玩家：他死亡。当你首次死亡后，你仍存活，但会被当作死亡。
- **要点**：
  - 僵怖第一次因任何原因死亡后保持存活，但说书人要表现得像他死了。第二次死亡时真正死亡，善良获胜（主谋另算）。
  - 被当作死亡时，几乎在所有方面都算死人：生命标记翻面，投过一次票后失去投票标记，不能提名，不算茶艺师的存活邻座等。区别是游戏继续、僵怖仍然能攻击，城镇广场上只剩两名其他存活玩家时游戏也继续。
  - 只有白天没人死亡时，夜里才被唤醒攻击。处决一个已经死亡的玩家不算有人死亡，僵怖照样醒。
  - 醉酒中毒的僵怖死亡 → 真正死亡，善良获胜。被当作死亡的僵怖醉酒中毒时，不要宣布他存活。
- **怎么运作**：僵怖第一次死亡时依然存活：宣布他死亡，但魔典里**不放**帷幕（城镇广场上照常翻生命标记），之后当作已死亡。每个白天有玩家死亡时，给那人放"死于今日"（僵怖因处决而"死亡"也要放）。首夜以外的夜晚：有"死于今日"就不唤醒僵怖；没有就唤醒，让他指一名玩家，那人死亡，放"死亡"标记。
- **提示标记**：
  - 死于今日：放置时机：白天有玩家死亡时（包括僵怖自己），不论死因｜放置条件：放在死亡玩家旁，不论僵怖此时是否醉酒中毒；一天多人死亡也只放一个｜移除时机：僵怖的夜晚行动结束后随时可移除，或黎明移除。
  - 死亡：放置时机：僵怖夜晚行动选人后｜放置条件：所选玩家当前存活、能被僵怖杀死、僵怖未醉酒中毒｜移除时机：黎明宣布后随时可移除。
- **规则细节**：
  - 胜负计数要用真实存活人数：被当作死亡的僵怖实际存活。城镇广场显示 2 人存活时，实际是 3 人，游戏继续；再死一人才是"只剩两人"，邪恶获胜。
  - 被当作死亡的僵怖不能被魔鬼代言人选择，不是教授能复活的对象，算作死人（月之子不能选他，推断）。
  - 刺客刺中未触发能力的僵怖 → 触发能力，被当作死亡并继续存活。
  - "首次死亡"包括夜里被自己选中、被教父、被刺客、被处决等任何原因。
  - 驱魔人选中僵怖：当晚即使无人死亡也不唤醒他攻击，但他的"首次死亡后存活"照常生效。
  - 相克规则：官方相克只涉及其他剧本，已略。
- **范例要点**：
  - 被处决、看似死亡 → 当晚不能攻击（今天有人"死"了）。后来广场上只剩两人存活，游戏继续，直到再有一人死亡。
  - 白天无人死亡 → 夜里攻击；第二天修补匠白天死亡 → 当晚不唤醒僵怖。
- **说书人注意**：
  - 魔典里要单独记录"僵怖已用掉假死"，和城镇广场状态分开（程序里：apparentDead = true，alive 仍为 true）。
  - 被当作死亡的僵怖被处决（第二次死亡）→ 真正死亡；如果主谋在场且清醒，触发主谋。
  - 和平主义者、茶艺师、魔鬼代言人保住了被处决者 → "今天无人死亡"，僵怖当晚会醒。

### 普卡（Pukka）
- **能力**：每个夜晚，你要选择一名玩家：他中毒。上个因你的能力中毒的玩家会死亡并恢复健康。
- **要点**：
  - 普卡**首夜就行动**：选一人，立即中毒。
  - 下一夜，在普卡做完新的选择之后，上一个中毒者死亡并恢复健康。
  - 驱魔人能让普卡当晚不被唤醒下毒，但上一个中毒者照样死。旅店老板保护上一个中毒者 → 他不死，随后恢复健康。
  - 醉酒的普卡选人 → 目标不中毒，下一夜也不会死。
  - 普卡上一夜选人时清醒、今晚醉酒 → 上一个中毒者今晚不死；普卡恢复清醒后中毒效果恢复，在随后的夜晚杀死他。
- **怎么运作**：每晚唤醒普卡，让他指一名玩家，让他入睡，给所选玩家放"中毒"。首夜以外的夜晚，其他带普卡"中毒"标记的玩家死亡：放"死亡"，移除他的"中毒"。
- **提示标记**：
  - 中毒：放置时机：普卡夜晚行动选人后｜放置条件：所选玩家能因普卡中毒，且普卡未醉酒中毒｜移除时机：普卡的能力让该玩家死亡时，在结算完该玩家的死亡触发能力后移除；或普卡死亡或离场时。
  - 死亡：放置时机：普卡的夜晚行动（以及可能的下毒）结束时｜放置条件：普卡未醉酒中毒时，不论这次有没有被唤醒、有没有成功下毒，检查**这次行动之前**已带普卡"中毒"标记的玩家（只看普卡的标记）：该玩家已死亡或无法被普卡杀死 → 直接移除"中毒"；否则放"死亡"，提醒黎明宣布。普卡醉酒中毒时跳过这一步，也不移除原有的中毒标记｜移除时机：黎明宣布后随时可移除。
- **规则细节**：
  - 普卡选自己 → 自己中毒，且这种中毒没有结束条件，永久中毒（隐性规则：自我中毒）。
  - "上一个中毒者"只算上一个**成功**中毒的人：醉酒时选的人被跳过（见范例）。
  - 普卡可以毒死人（例如已死亡的月之子），让其死亡触发能力失效。
  - 毒发死亡的玩家死时仍然中毒；毒标记要等他的死亡触发能力结算完再移除。
  - 中毒的玩家拿到的信息可以是假的（侍女、赌徒、驱魔人等都会受影响）。
  - 相克规则：官方相克只涉及其他剧本，已略。
- **范例要点**：
  - 毒侍女 → 侍女得到错误信息 → 下一夜侍女死亡。
  - 毒弄臣 → 第二天弄臣被处决死亡（没有能力）→ 下一夜无人死亡，普卡毒造谣者 → 再下一夜醉酒的普卡选修补匠（无效）→ 再下一夜恢复清醒，普卡让造谣者死亡（跳过修补匠）。
  - 毒和平主义者 → 下一夜驱魔人挡住普卡 → 和平主义者照样死亡，普卡不下新毒。
- **说书人注意**：
  - 实现时普卡的"中毒链"只保存一个"当前受害者"，普卡醉酒时冻结（不推进、不清除），清醒后继续。
  - 普卡选中莽夫（当晚首个）→ 普卡当场醉酒，见莽夫一节。
  - 被处决掉的中毒者当晚不会再死，所以那晚可能无人死亡，这是普卡的典型线索。

### 沙巴洛斯（Shabaloth）
- **能力**：每个夜晚*，你要选择两名玩家：他们死亡。你上个夜晚选择过且当前死亡的玩家之一可能会被你反刍。
- **要点**：
  - 首夜以外每晚攻击两人。
  - 下一夜，说书人可以让上一夜被他攻击过的两人之一（现在已死亡）复活。可以是攻击时还活着的人，也可以是攻击时就已经死了的人。
  - 被反刍者重新获得能力，包括用过的"每局限一次"能力。有"在你的首个夜晚"能力的，可以再用一次。
- **怎么运作**：首夜以外每晚唤醒沙巴洛斯，让他依次指两名玩家（一次一名），让他入睡。按选择顺序依次死亡，放"死亡"。之后每晚唤醒沙巴洛斯**之前**，说书人可以选一名带沙巴洛斯"死亡"标记、且已死亡的玩家复活：把"死亡"换成"复活"，移除帷幕。被反刍者的顺序如果在后面就照常唤醒；只在首夜行动的角色现在就唤醒。黎明先宣布死亡，再宣布复活（不说原因）。
- **提示标记**：
  - 死亡：放置时机：沙巴洛斯夜晚行动选人后｜放置条件：所选玩家当前存活、能被他杀死、沙巴洛斯未醉酒中毒，就正常放置；否则**仍要放**但倒置，表示无效、只记录被选过（回溯：看上一夜选过谁，不看是否因此而死）｜移除时机：下一夜轮到沙巴洛斯、唤醒他之前（结算完反刍后移除），或沙巴洛斯死亡或离场时。
  - 复活：放置时机：轮到沙巴洛斯夜晚行动、唤醒他之前｜放置条件：说书人决定是否让带沙巴洛斯"死亡"标记（正放倒放均可）且已死亡的玩家之一复活；沙巴洛斯此时醉酒中毒则无人复活，跳过｜移除时机：黎明宣布复活后随时可移除。
- **规则细节**：
  - 本剧本里，被反刍者的首夜能力可以在沙巴洛斯行动结束后立即使用。
  - 反刍是说书人的决定，玩家不能选。沙巴洛斯不能反刍自己（死了就没能力）。
  - 被驱魔人挡住的夜晚：不攻击，但反刍照常可以发生。
  - 被反刍的月之子、弄臣等重获能力，再次死亡时能再触发。
  - 被反刍者顺序在沙巴洛斯之后时当晚可以行动（珀、刺客、教父、教授、造谣者、修补匠、月之子、祖母、侍女）；在之前的不行动（如驱魔人）。
  - 相克规则：官方相克只涉及其他剧本，已略。
- **范例要点**：
  - 攻击造谣者和赌徒 → 造谣者死，赌徒受旅店老板保护存活。
  - 攻击存活的侍臣和已死亡的驱魔人 → 侍臣死；下一夜说书人反刍驱魔人 → 驱魔人当晚不行动（他的顺序在沙巴洛斯之前）。
  - 先攻击茶艺师的邻座（受保护）再攻击茶艺师 → 只有茶艺师死。
- **说书人注意**：
  - 反刍只偶尔用：每局一到两次通常就够了。反刍的通常是善良玩家，偶尔可以反刍爪牙。
  - 两个目标严格按顺序结算（茶艺师、莽夫的结果都依赖顺序）。
  - 沙巴洛斯在 5–6 人局很不公平（原文），注意"剩 4 人不处决 → 一夜两杀 → 邪恶获胜"。

### 珀（Po）
- **能力**：每个夜晚*，你可以选择一名玩家：他死亡。如果你上次选择时没有选择任何玩家，当晚你要选择三名玩家：他们死亡。
- **要点**：
  - 首夜以外每晚可以攻击一人，也可以不选。
  - 不选的话，下一次被唤醒时必须选三人。必须选，不能再不选。
  - 不选时醉酒中毒，下一次照样选三人。
  - 只有"不选任何人"才能换来三刀。攻击了某人但对方没死，不算。
  - 首夜不行动，不算"没有选择"。被驱魔人挡住的夜晚也不算"没有选择"（但前一晚没选的话，下一次被唤醒仍然是三刀）。
- **怎么运作**：首夜以外每晚唤醒珀，他摇头（不选）或指一名玩家，让他入睡。不选：给珀放"攻击三次"。选了：那人死亡，放"死亡"。唤醒时珀带着"攻击三次"：让他依次指三名玩家，按顺序依次死亡，各放"死亡"，然后移除"攻击三次"。
- **提示标记**：
  - 攻击三次：放置时机：珀夜晚行动并选择不攻击后｜放置条件：放在珀旁，不论他不选时是否醉酒中毒｜移除时机：下一夜轮到珀行动、结算完（此时要提醒他必须选三人）后移除。
  - 死亡：放置时机：珀夜晚行动选人后｜放置条件：所选玩家当前存活、能被珀杀死、珀未醉酒中毒｜移除时机：黎明宣布后随时可移除。
- **规则细节**：
  - "上次选择"指他上一次被唤醒并做选择的那次。被驱魔人挡掉的夜晚不算一次选择，"攻击三次"保留到下一次唤醒。
  - 三刀按顺序结算，选到莽夫那一刀起后面全部失效。
  - 相克规则：无。
- **范例要点**：
  - 第二夜攻击一人，第三夜不攻击，第四夜攻击三人。
  - 不攻击时醉酒 → 下一夜中毒，选三人都没死（三刀用掉）→ 再下一夜清醒，攻击一人，死亡。
  - 依次攻击月之子、莽夫、祖母 → 只有月之子死（攻击莽夫时醉酒）。
- **说书人注意**：
  - 被要求选三人时珀醉酒中毒，三刀同样用掉，"攻击三次"照常移除。
  - 剩 5 人时善良方不处决，珀可能一夜获胜（如果还有其他夜晚死因，人数门槛更高）。

## 五、本剧本的关键交互

**通用底层规则（实现时最重要）**
- **效果来源失效 → 效果立即终止**：角色死亡、醉酒或中毒时失去能力，他造成的持续效果立即停止（水手/旅店老板/侍臣/吟游诗人/莽夫造成的醉酒、普卡的毒、茶艺师/旅店老板的保护）。来源恢复清醒健康时，持续效果恢复。但醉酒中毒期间"使用或触发"的能力就此浪费（侍臣、教授、刺客）。
- **循环醉酒中毒**（隐性规则）：例如水手灌醉普卡、旅店老板灌醉水手（普卡因此清醒）、普卡毒旅店老板（水手因此清醒，普卡再次醉酒）→ 三人一同醉酒或中毒。到黄昏，水手和旅店老板的醉酒结束，普卡的毒仍在，只剩旅店老板中毒。自我中毒（普卡选自己）没有结束条件，永久中毒。
- **死亡逐个发生**：多目标击杀按选择顺序一个一个结算，每一次都按那一刻的状态判断保护（茶艺师、莽夫）。
- **死人不会再死**：攻击、处决死亡玩家不算死亡（不触发教父、吟游诗人，僵怖照样醒）。
- **"不能"压过"能"**：刺客无视所有"不会死亡"。
- **回溯型能力**：造谣者、月之子、教父、僵怖（"死于今日"）、普卡、珀、沙巴洛斯。判断看结算那一刻能力是否有效，触发条件发生时的醉酒中毒不影响。

**具体交互**
1. **普卡 vs 旅店老板**：旅店老板保护上一个中毒者 → 他不死，并直接恢复健康（中毒链断开）。
2. **普卡 vs 驱魔人**：驱魔人挡住普卡 → 当晚不下新毒，但上一个中毒者照样死。下一夜没有"上一个中毒者"可杀。
3. **普卡醉酒**（侍臣、吟游诗人、水手、莽夫）：当晚上一个中毒者不死，中毒链冻结；恢复后上一个中毒者在普卡下一次行动时死亡。醉酒时选的人不中毒、不算进链条。
4. **刺客无视保护**：旅店老板、茶艺师、清醒的水手、弄臣、莽夫都挡不住刺客。刺客杀莽夫 → 莽夫死并转邪恶。刺客杀未假死的僵怖 → 僵怖假死并继续存活。刺客杀孙子 → 祖母不死。
5. **弄臣与刺客 / 普卡**：刺客直接杀死弄臣（能力白留）。普卡毒弄臣 → 弄臣中毒期间没有能力，处决或毒发都会直接死。
6. **主谋在恶魔被处决后的结算**：恶魔死于处决、游戏本应结束 → 不公布，继续一夜一天。额外白天处决善良 → 邪恶胜；处决邪恶或不处决 → 善良胜。只剩两人也继续。僵怖第一次被处决不触发。主谋醉酒（侍臣、吟游诗人）→ 恶魔一被处决善良就获胜。
7. **教父被侍臣灌醉**：三天三夜内外来者白天死亡也杀不了人（"死于今日"照放，但击杀无效）。侍臣选"教父"时教父在场就命中，选到不在场的爪牙就落空（侍臣不知道结果）。
8. **莽夫被选中后的醉酒与阵营变化**：当晚第一个用能力选中莽夫的人立即醉酒（连这次选择都失效），莽夫转为他的阵营，可能立刻改变茶艺师的保护、月之子的判定（月之子看选人那一刻）、和平主义者能不能救他。说书人替能力选人（祖母的孙子）不算。
9. **茶艺师邻座保护**：两个存活邻座都善良才生效；挡恶魔、教父、造谣者、月之子、处决，挡不住刺客。邪恶邻座死后，新邻座可能重新受保护。被当作死亡的僵怖不算邻座。修补匠受保护时不能自然死亡。
10. **吟游诗人 vs 全场**：爪牙死于处决 → 全员醉酒到下个黄昏：恶魔、刺客、教父杀不了人，普卡链冻结，修补匠不会暴毙，和平主义者、魔鬼代言人当天无效，侍女、赌徒的结果不可靠。处决僵怖（第一次）时僵怖醉酒 → 真死，善良胜。
11. **驱魔人 vs 珀**：被挡的夜晚不算"没选择"；前一晚已经蓄力的珀，下一次醒来仍是三刀。
12. **驱魔人 vs 僵怖 / 沙巴洛斯**：挡住后僵怖假死能力照常，沙巴洛斯照常可以反刍。
13. **和平主义者 / 魔鬼代言人 / 茶艺师 / 水手 / 弄臣 → "处决但存活"**：一律只宣布"被处决但依然存活"。处决仍然算数（当天不再提名），算"今天无人死亡"（僵怖会醒），外来者没死也不触发教父。
14. **教授 / 沙巴洛斯反刍**：被复活者重获能力（包括用过的一次性能力），顺序在后的当晚就行动，祖母立即重新拿信息。黎明先报死再报复活，不说原因。教授只能复活镇民；反刍可以是任何角色。
15. **月之子 + 教父**：月之子白天被处决 → 月之子的诅咒和教父的击杀同一晚各自结算，可能一夜多死。
16. **祖母 + 恶魔**：只有恶魔（僵怖、普卡毒杀、沙巴洛斯、珀）杀死孙子才连带祖母；刺客、教父、月之子、造谣者、赌徒不连带。
17. **疯子 + 真恶魔**：真恶魔每晚都会得知疯子的目标（在驱魔人之前告知），可以跟刀伪装；疯子的选择本身没有任何效果。
18. **修补匠 + 教父 / 僵怖**：修补匠白天暴毙 → 教父当晚可杀人，僵怖当晚不醒。
19. **造谣者 + 水手 / 弄臣**：造谣者的死者由说书人选，推荐选能死的人；水手让自己醉酒时可以选他。
20. **魔鬼代言人 + 修补匠**：魔鬼代言人只挡处决致死，说书人仍可以在处决时用修补匠能力让他死。

## 六、常见判定速查

1. **问：醉酒的普卡选了人，那人会中毒、会死吗？** 答：都不会。醉酒时的选择没有效果，也不进入"上一个中毒者"的链条。
2. **问：普卡今晚被驱魔人选中，昨晚的中毒者会死吗？** 答：会。驱魔人只阻止普卡被唤醒下新毒，杀死上一个中毒者的部分照常结算。
3. **问：旅店老板保护了普卡昨晚毒的人？** 答：那人今晚不死，并恢复健康，不会再晚一夜补死。
4. **问：清醒的水手被处决？** 答：宣布"被处决但依然存活"，不说原因。水手醉酒时（包括选了自己）被处决会死。
5. **问：弄臣受茶艺师保护时被恶魔攻击，弄臣的能力用掉了吗？** 答：没有。只有在没有其他保护、弄臣真的将要死时才用掉。
6. **问：刺客刺弄臣、水手、茶艺师邻座、旅店老板保护的人？** 答：全部死亡。刺客醉酒中毒时则全部不死，但刺客的能力仍然用掉。
7. **问：僵怖第一次被处决？** 答：宣布死亡，城镇广场翻生命标记，魔典不放帷幕；今天有人"死亡"，当晚不唤醒僵怖。游戏继续，主谋不触发。
8. **问：广场上只剩 2 人存活，但僵怖在假死中？** 答：实际存活 3 人，游戏继续；再死一人才是邪恶获胜。
9. **问：白天处决了一名已经死亡的玩家，僵怖今晚醒吗？** 答：醒。死人不会再死，今天仍然无人死亡。
10. **问：主谋在场，恶魔被处决，第二天只剩两人存活？** 答：游戏继续这一天。处决善良 → 邪恶胜；处决邪恶或不处决 → 善良胜。
11. **问：外来者在夜里被恶魔杀死，教父当晚能杀人吗？** 答：不能。只算白天死亡（任何原因）。白天死两个外来者也只杀一人。
12. **问：外来者被处决但被和平主义者救下？** 答：没有死亡，教父不触发。
13. **问：侍臣醉酒时用了能力？** 答：无效，能力用掉，之后不再唤醒，恢复清醒也不补。
14. **问：侍臣生效后侍臣死了？** 答：目标立即恢复清醒（醉酒标记移除）。
15. **问：吟游诗人在场，邪恶的莽夫被处决并死亡？** 答：不触发。莽夫是外来者，不是爪牙。
16. **问：茶艺师的邻座在夜里被沙巴洛斯先攻击，随后茶艺师也被攻击？** 答：邻座受保护存活，茶艺师死亡。顺序反过来（先杀茶艺师）时，后被攻击的邻座就不受保护了。
17. **问：珀被驱魔人挡住的那晚算"没选人"吗？** 答：不算。只有珀醒来后自己选择不攻击才算；但如果前一晚已经不选，被挡后的下一次醒来仍是三刀。
18. **问：月之子被处决但因和平主义者存活？** 答：没有死亡，不能选人。
19. **问：月之子选人时阵营看哪一刻？醉酒看哪一刻？** 答：阵营看选人那一刻（善良的莽夫之后变邪恶也照样死）；醉酒中毒看夜里结算那一刻。
20. **问：教授能复活疯子、僵怖或被反刍的人吗？** 答：疯子是外来者、僵怖是恶魔，都无效但能力用掉；被反刍者已经存活，不能选，要让教授重新选死人。
21. **问：侍女查的两人中，一个是被唤醒但摇头不用能力的刺客或侍臣？** 答：计入（被唤醒就算）。被驱魔人挡住、只因驱魔人被唤醒的恶魔不计入。
22. **问：修补匠能在只剩 3 人时被说书人杀死、让邪恶获胜吗？** 答：规则允许，但官方明确建议永远不要用修补匠结束游戏。
