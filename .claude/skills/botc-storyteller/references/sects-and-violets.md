# 梦殒春宵（Sects & Violets）说书人参考

官方中文名是《梦殒春宵》（殒，不是陨）。难度**中等**，最疯狂的基础剧本：善良信息极多，但信息不可靠；角色和阵营都会中途改变；第一次出现「疯狂」机制。
这份是读官方百科后用自己的话整理的（本地没存角色页原文），拿不准时回官方百科查对应角色页的「规则细节」。2026-10-31 逐页对过 25 个角色页和《夜晚行动顺序一览》。

- **善良方**：先判断是哪种恶魔在场，才知道信息该怎么读。涡流在场时镇民的信息全错，诺-达鲺在场时恶魔两侧最近的镇民中毒。外来者常常要藏身份。
- **邪恶方**：要决定给别人真信息还是假信息，因为好人会按「可能的恶魔」倒推。爪牙（麻脸巫婆、女巫、洗脑师）都能间接杀人或搅局，但死后现象消失，容易被推出来。

## 一、人数和配置

人数表与其他剧本相同。会改配置的两个恶魔：
- **方古 [+1 外来者]**：放标记前把一个镇民换成外来者。
- **亡骨魔 [-1 外来者]**：把一个外来者换成镇民；没有外来者可减就不变。

## 二、夜晚顺序（以百科「夜晚行动顺序一览」为准）

麻脸巫婆排在舞蛇人之前：百科后来调过，好让她造出的爪牙当晚能行动。她造成的死亡仍然要等到第一个恶魔行动之前才发生。剧本页的旧表还把她排在洗脑师后面，以一览表为准。

- **首夜**：哲学家 → 爪牙信息、恶魔信息（7 人及以上）→ 舞蛇人 → 镜像双子 → 女巫 → 洗脑师 → 钟表匠 → 筑梦师 → 女裁缝 → 数学家
- **其他夜晚**：哲学家 → 麻脸巫婆 → 舞蛇人 → 女巫 → 洗脑师 → 方古 → 诺-达鲺 → 涡流 → 亡骨魔 → 理发师 → 心上人 → 贤者 → 筑梦师 → 卖花女孩 → 城镇公告员 → 神谕者 → 女裁缝 → 杂耍艺人 → 数学家

## 三、角色要点

### 镇民
- **钟表匠**：首个夜晚得知恶魔和最近爪牙的距离（邻座为 1，死人也算，顺逆时针取小）。无恶魔或无爪牙时是 0。每次都按当前场上情况算。
- **筑梦师**：每晚选一名其他玩家，得知一善一恶两个角色，其中一个是他的真实角色（看真实角色类型，不看阵营）。不会被告知涡流这个真角色：涡流在场时必须两个都错。
- **舞蛇人**：每晚选一名存活玩家。选中恶魔：两人互换角色和阵营，原恶魔永久中毒（直到死亡或离场）。不是恶魔则无事发生。
- **数学家**：每晚得知从上个黎明到他醒来时，有几名玩家的能力因别人的能力而没有正常生效。检测的是**结果**：中毒但碰巧拿到真信息不算；同一个人一天最多算一次；不算他自己。
- **卖花女孩**：每晚*得知今天白天有没有恶魔投过票。死恶魔的幽灵票也算；换了恶魔也按当时的恶魔算。
- **城镇公告员**：每晚*得知今天白天有没有爪牙发起过提名。
- **神谕者**：每晚*得知死亡玩家里有几名邪恶（按阵营，以黎明时的状态为准）。
- **博学者**：每个白天可以私下问一次，得到一真一假两条信息。醉酒中毒时可能两真或两假；涡流在场时两条都假。
- **女裁缝**：每局一次，夜里选两名其他玩家（生死不限），得知是否同一阵营。失效时也算用掉。
- **哲学家**：每局一次，夜里选一个善良角色，获得其能力（不变成该角色）。该角色在场时其持有者醉酒；哲学家死亡、醉酒、改变角色后对方恢复。之后该角色才出现在场也会醉酒。在场有多人时只醉一人，优先存活的。首夜类能力当晚就用。
- **艺术家**：每局一次，白天私下问一个是非问题，答是 / 不是 / 我不知道。含糊、嵌套的问题可以答我不知道（能力也算用掉）。
- **杂耍艺人**：在他的首个白天可以公开猜最多五次玩家的角色，当晚得知猜对几个。猜测时失效而当晚健康，仍给真信息。邪恶可以假装。
- **贤者**：被恶魔杀死时，当晚得知两名玩家，其中一名是杀他的恶魔。死于其他原因不触发。

### 外来者
- **畸形秀演员**：如果「疯狂」证明自己是外来者，可能被处决（计入每天一次的处决；官方连夜里都可以处决）。
- **心上人**：死亡时说书人选一名玩家永久醉酒（心上人醉酒中毒时不触发；被方古转化时没死，不触发）。
- **理发师**：死亡当晚，恶魔可以选两名玩家交换角色（阵营不变），不能选其他恶魔，可以选自己，可以放弃。
- **呆瓜**：得知自己死亡时要公开选一名存活玩家，选中邪恶则己方落败。邪恶的呆瓜选中邪恶则善良获胜。

### 爪牙
- **镜像双子**：与一名对立阵营玩家互知角色。善良的那个被处决，邪恶获胜。两人都存活时善良无法获胜（恶魔死了也继续）。同阵营了由说书人重新配对。死亡的镜像双子失去能力。
- **女巫**：每晚选一名玩家，他明天发起提名就死（提名仍然有效）。只剩三名存活玩家时她立刻失去能力，诅咒也解除。
- **洗脑师**：每晚选一名玩家和一个善良角色，他明天白天和夜里要疯狂证明自己是这个角色，否则可能被处决。可以选死人（官方连死人都能处决，计入当天的处决）。
- **麻脸巫婆**：每晚*选一名玩家和一个角色，该角色不在场（死人的角色也算在场）时那名玩家变成它，阵营不变。造出恶魔时当晚死亡由说书人决定：可以多杀或阻止恶魔的击杀，由她造成的死亡不触发贤者，时机在第一个恶魔行动之前。

### 恶魔
- **方古**：杀外来者时，改为外来者变成邪恶方古、原方古死亡，每局一次；新方古不知道爪牙。没真杀成（比如选到死人）不算。
- **亡骨魔**：被他杀死的爪牙保留能力（夜里继续行动），并让该爪牙某一侧最近的镇民中毒。亡骨魔死亡或失效时都恢复。
- **诺-达鲺**：两侧最近的镇民（生死不限，跳过非镇民）持续中毒，随座位和角色动态变化。
- **涡流**：镇民的能力都产生错误信息（醉酒中毒也一样）；白天没有人被处决，黄昏邪恶获胜。规则解释、角色变化通知不算能力信息。

## 四、胜负
- 所有恶魔都死亡（或离场）且镜像双子没有挡着：善良获胜。恶魔死了但两个双子都活着：游戏继续，夜里不再有人死。
- 只剩两名存活玩家：邪恶获胜。官方这条只看人数：恶魔死了但双子挡着善良时，只剩两人也是邪恶赢（善良没有达成胜利条件，不算同时达成）。
- 善良双子被处决、呆瓜选中邪恶、涡流在场且当天没有处决：见各角色。

## 五、疯狂
「疯狂」的意思是努力说服别人相信某件事。简短暗示不够，不按要求做的可能被处决，「可能」表示说书人可以放过（比如防止邪恶靠这个获胜）。处决计入每天一次。

## 六、本项目的改写
- **AI 判定疯狂**：有转写服务时，被洗脑的真人玩家要打开收音页（屏幕中间会提示），转写交给大模型判断，公开声明不算数；不开收音处决概率明显变高，只声明不开收音低一些。开不了收音的（机器人、掉线）或服务器没有转写时，公开声明就算尽力。说漏嘴当场判：收音转写命中破功的说法（被逼、洗脑、真实角色等）才问快速模型，第一次只警告本人，第二次掷骰子处决；努力够不够还是黄昏判。自家机器人的服务器上还可以打开「语音判定疯狂」：机器人常驻广场转写。真人说书时由说书人判定（魔典工具里有处决按钮）。
- **博学者**：AI 说书时用真实局面生成的模板句，保证真的就是真的、假的就是假的。
- **艺术家**：AI 说书时交给大模型判断，没配或失败时答「我不知道」。
- **疯狂何时判**：AI 说书在黄昏判当天白天的表现。当天的处决还空着就处决（死人也判，占掉当天的处决，能挡涡流）；已经有处决或台上有人时，活人留到入夜处决，当场公布，不占明天的处决。夜里没人说话也不能声明，所以夜晚的疯狂不单独判。真人说书时魔典工具白天夜里都能用。
- **杂耍艺人不猜**：公开声明后可以一个都不猜，当晚得知 0；完全不声明就没有当晚信息。
- **两个呆瓜同时死**：按死亡顺序一个一个选，第一个定了胜负第二个就不用选。夜里被处决的呆瓜当场选，夜里被杀的等天亮。
- **旅行者、实验性角色**：不做。
