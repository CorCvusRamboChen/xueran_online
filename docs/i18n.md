# 中英双语（英文版）

2026-11-20 用户要一个整体的英文版：玩家可以在中文和英文之间切换。

## 玩家怎么切

- 设置面板（大厅「声音、字号和语言」，对局里的「设置」）→ **语言 · Language** → 中文 / English。换了以后页面重新加载。
- 链接带 `?lang=en`（或 `?lang=zh`）直接用那个语言，并记在本机。
- 都没选过就是中文（很多中文玩家的系统是英文的，按系统语言猜会把他们突然换成英文）。
- 选择存在本机（localStorage `botc-lang`），不跟账号走。

## 原理：中文就是词典的键，代码不用改写

- **英文在 `src/shared/i18n/en/*.json`**：`{ "中文": "English" }`。按块分文件（`scripts/i18n/areas.mjs` 定的：lobby、ui、server、engine……），一个键只在一个文件里。
  `00-official.json` 是生成的（见下），`zz-overrides.json` 放少数要改口的（同一句中文在别处要不同英文时）。
- **客户端**：打包时 `scripts/i18n/babel-plugin.cjs` 把代码里带中文的东西自动换掉：
  - `'中文'` → `__t('中文')`
  - `` `第 ${n} 夜` `` → `__tt('第 {0} 夜', [n])`（键里 `${…}` 按顺序换成 `{0}` `{1}`…）
  - JSX 同一行里的文字和 `{…}`、`<b>…</b>` 合成一句：`<p>你有 {n} 票</p>` → 键 `你有 {0} 票`
  - `title="提示"` 这类属性
  - 不动：import 路径、对象的键、`obj['中文']`、正则、`console.*`、着色器代码。
  运行时 `client/src/i18n.js` 按语言查词典；中文下原样返回，**中文界面和以前一字不差**。英文词典只在英文下才下载。
- **服务器**：照旧生成中文（引擎、房间、旁白都不用改）。发给每个连接之前（`index.js` 的 `broadcast` 和 `reply`），
  英文连接的整份状态用 `localize()` 翻：先整句查词典，查不到就把带 `{0}` 的键编成正则反查、参数再递归翻（角色名、名字、数字），
  再不行按句读、括号、「与」拆开分段翻。所以**同一个房间里可以有人中文、有人英文**。
  - 名字字段（`name`）只换机器人和词典里有的（教程人物、地点、角色名），真人的名字原样。
  - 固定格式的行（魔典的「【邪】4号 名字 — 角色（标记）」）在 `core.js` 的 `RULES` 里整行换，客户端按英文格式排表。
- **旁白配音**：英文玩家听英文配音（`tts.js`，默认 `en-GB-RyanNeural`，环境变量 `AZURE_TTS_VOICE_EN` 可换）；每个人按自己的语言听。
  没配 Azure 时浏览器自带语音按界面语言读。
- **AI 说书人**（`judge.js`）：赛后总结、军事法庭判词、7 号空座的发言、渔夫的建议，按**房主**的界面语言写（`room.aiLang()`）。
  中英混桌时以房主为准。判定用的提示词还是中文。

## 角色名、能力、剧本名：官方英文

`00-official.json` 由 `scripts/i18n/gen-roles.mjs` 从官方数据生成（The Pandemonium Institute 的 botc-release 仓库 `resources/data/roles.json`）：

```
curl -sSL -o roles.json https://raw.githubusercontent.com/ThePandemoniumInstitute/botc-release/main/resources/data/roles.json
node scripts/i18n/gen-roles.mjs roles.json
```

中文能力后面我们加的操作提示（「（在行动面板里点「开枪」）」）会接成英文（`(Tap "Shoot" in the action panel.)`），按钮名取界面词典里的译法。
狼人杀、阿瓦隆、暗印的角色不是血染角色，走普通翻译。

## 改了代码以后

```
node scripts/i18n/areas.mjs --sync     # 新出现的中文加进词典（值是空的），代码里没了的键删掉
node scripts/i18n/extract.mjs          # 列出还缺英文的句子（按文件）
node scripts/i18n/check.mjs            # 词典格式：空的、英文里还有中文、占位符对不上
```

`test/i18n.test.js` 保证：代码里每句中文都有英文；英文玩家从大厅到一局暗流涌动结束，收到的画面里没有残留中文。

### 写英文词条

- `{0}` `{1}` 是参数，顺序可以换；`{0|vote|votes}` 按参数 0 的数字选单复数。
- `**加粗**`、`\n` 保留；「」换成英文引号；座位 `{0}号` → `#{0}`。
- 片段（会被拼进别的句子的半句话）前后要空格、逗号的，直接写在英文里（整句命中词典时原样用）。
- 术语：说书人 Storyteller、魔典 Grimoire、镇民/外来者/爪牙/恶魔/旅行者/传奇角色 Townsfolk/Outsider/Minion/Demon/Traveller/Fabled、
  死人票 Ghost vote、提名 Nominate、处决 Execute、醉酒/中毒 Drunk/Poisoned、自由活动 Free roam、集合 Gather、私聊 Private chat。

### 写代码时要注意

- 客户端**不要用正则或 `includes` 去解析服务器发来的中文**：英文玩家收到的是英文。要判断就写成 `text.includes('中文')`
  （插件会把字面量也翻成英文，两边对得上），或者服务器多发一个字段。现有的几处（Stage 的卡片标题、复盘的标签、魔典行）已经两种都认。
- 服务器拼名单用「、」或「 与 」都行（会被拆开翻）；尽量用完整的模板句，别把半句话当参数拼。
- 相邻的两个参数（`${a}${b}`）反查时分不清界线，能加个字隔开最好。

## 已知的限制

- 语音判定疯狂（`stt.js` 的本机转写）和灵言师的关键词只认中文语音；英文玩家的疯狂靠说书人判。
- 玩家自己打的字（艺术家的问题、造谣者的声明、失忆者的猜测）原样交给 AI 判，AI 能读英文；但几处按关键词的规则兜底（`guessLevel`）只认中文。
- KOOK 机器人的消息、Discord 语音频道名、服务器日志不翻（KOOK 是中文平台）。
- 官网（`site/`）不在这次范围里。
