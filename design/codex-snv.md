# 梦殒春宵 · 美术（交给 Codex）

第三个剧本《梦殒春宵》的美术，分两批：25 张能力牌、一整张小镇。做法和《暗流涌动》《黯月初升》完全一样，只换内容。
画的都是原创内容，不要直接照搬官方角色图或原作里的具体人物。

## 二、小镇

主题：**初夏傍晚的鸦木布拉夫**。官方背景故事：园丁让公园和窗栏开满花，鸟在唱歌，艺术家拿起画笔，哲学家在热闹的酒馆里思考，镇子周围搭起老旧的帐篷；人们在宴会上狂欢，女巫和异教徒却躲在郊区的宏伟遗迹和地下洞穴里，密谋渗透城镇。空气甜得让人不安。和前两张图形成对比：不要雪，不要枯叶，色调是暖粉、紫、草绿和傍晚的橙，阴影偏紫。越往东南角，花越少、颜色越冷。故事和位置的对照见 `design\snv-map\README.md`。

1. **布局底稿（最重要）**：`design\guides\snv-town-guide.png`（**3820×2080**，比前两张大，因为东南角的遗迹要整块画进去），等距方块图，1 像素 = 世界 1 单位。
   - **四个分区要一眼分得清**，底稿的地面颜色就是分区：
     - 紫罗兰花园（中间，环路以内）：最亮最甜，修剪过的鲜绿草坪，花和彩旗。
     - 花街（北到东）：暖色，路铺碎石块，窗台开花，干净整齐，有人住的样子。
     - 马戏营地（西到南）：踩秃的黄土和干草，路上压着车辙，木箱、桶、旧帆布，乱而热闹。
     - 遗迹郊野（东南）：灰绿、偏冷、有薄雾，石板路碎得露出地面，枯树、碎石，没有花。
     - 分区之间慢慢过渡，不要画出硬边。
   - 7 块白色空地 = 能进去私聊的房子，**底图上不画房子**，只画成地面。
   - 2 栋民居 = 不能进的普通建筑，画在底图里，窗户**全暗**（只有能进的房子亮灯），每扇窗下都有开满花的窗台花箱。南边的**废屋**没有花，窗户破了，是花街和遗迹之间的过渡。
   - 4 顶条纹帐篷、1 辆弧顶篷车、1 辆**空兽笼车** = **老旧的马戏营地**，也画在底图里：帆布褪色、打着补丁、绳子松了，和崭新的马戏大帐形成对比。不亮灯。南边两个条纹布篷是**小吃摊和售票亭**。
   - 大路口的**路牌**：两块彩色木板，金色指花街、红色指营地、灰色指遗迹、紫色指花园，靠颜色认路，**不写字**。
   - 小木箱、木桶、长椅、旗杆、碎石堆、枯树、火盆都按底稿的位置画。它们挡路，位置不要改。
   - 中间八边形环路是石板路；四条穿过拱门的路通向中央；路的宽窄、走向照底稿，不要改。
   - 集合点：圆形石板地，正中是**石雕喷泉**，水是淡紫色的，水池中间立着一根缠满紫罗兰的高**花柱**，顶上一圈花冠。它是全镇最常看见的认路标志。
   - 花园里两张**宴会长桌**：白桌布、酒杯、吃了一半的菜、花束，几把椅子歪着，像大家刚离开。
   - 环路里面那圈灌木（16 团）是**树篱**：修剪过的绿篱，开满紫罗兰。东南西北四个缺口已经有**花架拱门**，木架缠满花，这是大家必经的地方，要显眼。
   - 东南的石头建筑 = **宏伟遗迹**：两级台基上两排巨大的断柱，一段横梁还架着，体量要大，比镇上任何房子都古老；旁边是**遗迹断塔**，塌了一半，爬满藤蔓，塔脚破口是黑的（进不去，不能亮）。遗迹外面一圈**矮断墙**，通往遗迹的小路穿过一道塌了半边的**断石门**，这是进遗迹的正门。
   - 地上 3 个黑洞石圈 = **通往地下洞穴的暗口**（酒馆后、杂耍小棚旁、花园里）：很小、不显眼，用旧石头围着，周围的花枯了一小圈。这是小镇已经被渗透的线索。
   - 花圃按底稿的位置画，鸟画在屋脊和拱门上（底稿没有，不要挡门）。
   - 地面：草地和花丛，路边散落彩旗、灯串、小摊的木箱。
