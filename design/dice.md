# 说书人的骰子

判定不写死，掷一次，各种情况给加减值。代码在 `src/engine/dice.js`，所有数字都在 `DICE`（要不要做）和 `DRAW`（挑谁）两张表里。

- 点数加在对数几率上，所以不会加到 100%。
- 概率永远留在 5%–95%：总发生或总不发生的事，没有数据能告诉我们换个做法会怎样。
- 表里没写的情况权重是 0：照样进决策日志，但不影响结果（影子信号）。先看有没有用，再给权重。
- 真正写死的只有规则和「不用疯狂定胜负」：`decidesGame` 的放过不掷骰，日志里标 `forced`。
- 造谣者挑谁死仍然硬排除新手：这个人会死，不靠概率。
- 战绩只在开局读一次，读不到也能开局。信号读取出错不影响结算。

## 用了哪些情况

| 情况 | 从哪来 | 用在 | 状态 |
|---|---|---|---|
| 局势 `balance` | 死亡、提名得票 | 错误登记、镇长替死、修补匠等 | 生效，疯狂判定故意不用 |
| 新手 `newbie` | 房主标记 | 疯狂从宽，挑人时避开 | 生效 |
| 打得少 `rookie`（不到 3 局）、老手 `veteran`（20 局以上） | 战绩 | 疯狂尺度（官方：新手宽老手严） | 生效 |
| 掉线 `offline` | 连接状态（刚重启没有操作记录的不算） | 疯狂从宽：掉线的人没法证明自己 | 生效 |
| 疯狂的依据 `heardFalse` / `silent` / `blind` | 语音判定 | 听到判没努力最重，没人在听最轻。`silent` 要真有人在听：他传过收音，或机器人在广场且他今天没进屋说话（`Room.listeningTo`） | 生效 |
| 转写听到 `voice` | 语音判定 | 畸形秀演员：转写可能听错，比公开声明轻 | 生效 |
| 被挑中过几次 `hits`（最多算 2） | 决策日志 | 替死、造谣者、心上人、旅店老板：别总盯着一个人，但比新手保护轻 | 生效 |
| 怀疑 `heat` | 提名得票 | 传位给谁 | 生效 |
| 玩家标记 `marksHeat`、`demonMarks`、`split`、`coverage` | 小魔典 | 无 | 影子 |
| 技术差距 `skillGap` | 两边真人的历史胜率 | 无 | 影子 |
| 服务器偏向 `townBias` | 这个服务器善良胜率（10 局以上） | 无 | 影子 |
| 打到哪了 `stage` | 死亡比例 | 无 | 影子 |
| 挂机 `idle` | 最后一次操作 | 无 | 影子 |
| 打过几局 `games` | 战绩 | 无 | 影子 |

存档里还多了 `meets`（谁和谁进了同一间屋）和 `records`（开局时的战绩）。`meets` 还没变成信号：要先看社交图有没有用。

## 还没有、但值得要的数据

- 语音里说了什么身份：现在只有公开声明进得了 `claims`，假世界配合不了语音里的伪装。全程转写有成本，也更敏感。
- 谁说了多少话：能看出冷场和被冷落的人，但要全程听语音。
- 投票前后的改票：现在只留最终票型。
- 赛后一两题问卷：紧张不紧张、公平不公平。这是唯一能直接判断好不好玩的数据。

## 权重怎么来的

局势的斜率是照旧公式对上的（`0.3 + 0.3 × 局势` 之类），差别在两头：旧公式被截在一个范围里，新的是平滑的。其余加减值是拍的，等真实对局的日志来调。

怎么调：每条决策日志有 `features`（当时的情况）、`prob`（抽中的概率）和 `chosen`。目标不要用胜率（差 3 个百分点每组要 4000 多局），用玩家标记的变化和问卷。数据少的时候只调几组共用的数（比如「局势影响多大」），不要每种判定单独调。
