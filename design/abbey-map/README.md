## 为什么是修道院

所有剧本都在官方背景「鸦木布拉夫」里。三个官方剧本各有一张图，其他十几个剧本都是在这三张图上换颜色和天气：

| 剧本 | 官方背景故事 | 我们的地图 |
|---|---|---|
| 暗流涌动 | 乌云压着沉睡的小镇，迷信的居民；晾衣绳在屋舍间起舞，烟囱冒烟，坩埚冒泡；鹅卵石街道、藤蔓墙；雷声里母亲叫孩子回家，近处森林有回声，**远处一座修道院里有人影在门洞间穿行** | 暴雪夜的钟楼海港（网格街道） |
| 黯月初升 | 冬日暮色，枫叶被黑斑侵蚀，森林等雪；岩隙里狼嚎，鸦群惊飞；旅行者躲进旅店喝茶听曲喝麦酒，邪恶的眼睛逼近 | 深秋黄昏的森林驿站旅店（溪谷切开两岸） |
| 梦殒春宵 | 夏天到了，公园和窗栏开满花，艺术家作画，哲学家在酒馆，马戏团搭帐篷；女巫和异教徒躲在郊外遗迹，在地下洞穴密谋 | 初夏傍晚的紫罗兰花园庆典（环形路网） |
| 社区和小剧本 | 没有自己的背景故事 | 借上面三张换色调和天气 |

用户要的是「比较符合共通的背景」，所以不去江南、沙漠这些鸦木布拉夫以外的地方，挑一个**背景故事里提到、但三张图都没去过**的地方：暗流涌动故事里远处的修道院。它是所有剧本都能用的「通用」场景：僧侣、驱魔人、送葬者、女祭司、修行者、图书管理员、厨师、祖母这些各剧本常见的角色都能在里面找到自己的房间；处决、守灵、告解、钟声又正好是这个游戏的调子。

## 身份证

| 项 | 内容 |
|---|---|
| 主体 | 山上的修道院（回廊中庭 + 教堂） |
| 地标 | 主：上院正中的钟楼（大石阶顶上，三层台地都看得见）；辅：回廊古井（集合点） |
| 路网 | **台地**：山坡被两道挡土墙分成下院、回廊、上院三层（三张旧图分别是网格、溪谷两岸、环形，都没有台地） |
| 相遇引擎 | 正中的两段大石阶：上下层都要从这里过 |
| 替代路 | 东边崖径（三层都通，绕远、安静）；西边墓园小石阶（回廊直下墓园） |
| 闭环 | 回廊 → 墓园小石阶 → 下院横路 → 大石阶 → 回廊 |
| 偏远房间 | 隐修石窟：东北崖上，走崖径一路被看见，测试保证它是全图最远的房间 |
| 分区 | 上院（肃穆、石板、风）、回廊（安静、药草畦）、下院（农庄、泥路、车辙）、崖径（冷、松树、碎石） |
| 季节时刻 | 初春清晨，细雨和山雾（暴雪夜、深秋黄昏、初夏傍晚之外的第四种） |
| 环境叙事 | 墓园里新翻的土；回廊晾衣架上的衣物（暗流涌动故事里的晾衣绳）；山门两边整夜没灭的火盆；崖径上塌下来的碎石 |

## 能进的 7 间房子

| 房间 | 位置 | 对应的常见角色 |
|---|---|---|
| 修道院教堂 | 上院东 | 僧侣、女祭司、驱魔人 |
| 院长居所 | 上院西 | 镇长、贵族、政客 |
| 隐修石窟 | 东北崖上（最远） | 修行者、隐士 |
| 缮写室 | 回廊西 | 图书管理员、调查员、教授 |
| 食堂 | 回廊东 | 厨师、旅店老板、茶艺师 |
| 药草房 | 下院东 | 投毒者、医生、草药 |
| 墓园（露天） | 下院西南 | 送葬者、守鸦人、掘墓 |

门都开在看得见的一面（南），入户路都是直的、正对着门（见记忆「地图不要绕门的路」）；墓园露天，门朝北对着下院横路。
